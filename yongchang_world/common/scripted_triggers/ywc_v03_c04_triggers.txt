# variables are per-country with the ywc_c04_ prefix; every cross-country read
# stays inside an explicit c:XXX ?= { } block so no variable is read outside
# its writer's scope. Stage values: 1300/1301 organizer investigation, 1302

# (country awaits the renegotiation window), 1320 (organizer awaits
# renegotiation answers), 1321 (country awaits the settlement round), 1322

# claimant's own scope; each case_ready_* guard pins c:<TAG> ?= this) -------
