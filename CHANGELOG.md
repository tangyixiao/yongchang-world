# Changelog

## v0.1.0-rc1 (prepared)

- Added the ten-country Yongchang World content slice for Victoria 3 1.13.11 (Matcha).
- Corrected the shared maritime trigger to use the 0–100 `ywc_maritime_network_level` threshold rather than a fixed country whitelist, so maritime dynamic names and flags can actually activate after route progress; aligned SHU's dynamic identity with Shun/Dashun in both languages.
- Added bounded AI guardrails and DLC compatibility gates for `ep1_content`, `mp1_content`, and `ep2_content`.
- Connected the ten startup-assigned country strategies to the active diplomatic AI layer: route progress, diplomatic crises, subject status, and bankruptcy now adjust each country's caution, while country-specific building and goods priorities remain bounded. Removed the unused `ai_strategy_ywc_guardrail_*` mirror definitions.
- A fresh isolated no-DLC preload (`none/25`) mounted the Mod, matched 1.13.11, matched the requested empty DLC set, and found no Mod parser/runtime vocabulary errors. This is loading evidence only; no campaign or long-run balance claim is attached.
- Guarded every late-route `var:` comparison with an existence check, then re-ran the isolated no-DLC preload (`none/26`) with the same clean parser/runtime result.
- Closed the first real Mod-load runtime findings: removed unsupported custom interest-group database objects; moved distribution-of-power laws out of the governance group; stopped redeclaring vanilla KOR/LAN dynamic-name and MNG/TIB/KOR/LAN flag lists; replaced invalid 1.13.11 modifier types and the missing ideology icon; added the full diplomatic-action notification localization and icon; removed orphaned event definitions; and wired DLC/route decision variables into journal completion checks. A fresh isolated manual preload (`manual-gate4-04`) mounted the Mod, matched 1.13.11, loaded 2326 events, and reported no Mod-specific errors. This is still preload evidence, not a campaign or balance claim.
- Added hidden-launch mount checks, bilingual content, political identities, dynamic names, colors, and geometric CoA definitions that reuse the vanilla pattern atlas; MNG/TIB/KOR/LAN keep their vanilla flag-definition lists to avoid duplicate database keys.
- Added the `ywc_nmg_autonomy_negotiation` diplomatic pact action: New Ming can open autonomy negotiations with Mexico while a subject and carrying the New Ming–Mexico chain journal; acceptance resolves the chain. Bilingual localization included. The in-game smoke suite gained a read-only `ywc_nmg_autonomy_action_ready` check, and engine strings confirmed `tools/scripted_tests` as the exact path the game queries for it.
- Replaced 57 placeholder journal and route titles (all ten countries) with proper English and Simplified Chinese display names, and added a localization parity test that keeps both languages key-aligned and placeholder-free.
- The smoke log collector now records `mod_mount` (mounted / not_mounted / unknown_no_debug_log) with the verbatim mount line in its summary; a fresh hidden launch re-verified `status=clean` with `mod_mount=mounted`.
- Normalized the in-game smoke suite's date literals to the vanilla bare form and statically grounded its trigger vocabulary against vanilla and mod precedents.
- Wired all ten countries' journals for playability: every one of the 71 journal completion variables now has a setter, with real bilingual decision events following the content_catalog success/failure/abandon outcomes contract (DMG, NQG, SHU, JHG in earlier rounds; OIR, MNG, TIB, KOR, LAN, NMG in the final round; the shared ocean-frontiers journal covers MHG and NMG). The known-unwired allowlist is now empty.
- Fixed `install_dev_mod.ps1` for Windows PowerShell 5.1: the PS6+ `utf8NoBOM` encoding switch failed parameter binding on the machine default, so the documented install path did not run; the descriptor is now written BOM-free via `UTF8Encoding($false)`.
- Fixed the observation runner writing a UTF-8 BOM `content_load.json`, which the game rejects and silently falls back to "all DLC enabled, no mods". The runner now writes BOM-free JSON and records `mod_mount`, version-match evidence, observed DLC mounts, and ownership-backend state per hidden launch. A `-NoLaunch` rerun over an already-verified run now preserves the recorded evidence instead of overwriting it.
- Probes established that directly launched executables ignore `disabledDLC` when the ownership backend reports ownership, and that the backend flips between all-owned and none-owned across launches; single-DLC observation configs remain pending instead of being claimed as loaded.
- Fixed actual game-side script and campaign-start parsing failures found in a user-launched campaign: added UTF-8 BOMs to Mod script/localization files, removed unsupported journal `visible` clauses, replaced unknown `is_country` checks with `this = c:TAG`, removed the duplicate `ywc_shu.6` definition, added the required `STATES` wrapper to state histories, converted building history levels to `add_ownership.country.levels`, renamed dotted reserved variables, moved `add_modifier` targets into the static modifier database, and made the development installer create the local-Mod directory junction expected by the current launcher. A fresh hidden launch now has zero Mod parser errors; the regression suite is 119 tests..
- Fixed the two runtime findings from the first real campaign: event option buttons showed raw keys because event option names and localization keys used different forms — all 190 bilingual option keys now use the same dotted event form as vanilla and are locked by localization tests; and the map showed unowned-province fragments because two Australian state ledgers only partially covered their vanilla regions (839 provinces) — the vanilla ownership blocks were restored from the baseline, state coverage is now asserted by a dedicated test, and duplicate cross-ledger state definitions (including one assigning provinces to undefined tags) were removed.  The lobby screenshot then identified the mosaic root cause: the mod's five partial state ledgers coexisted with vanilla's `00_states.txt`, so both executed for the same states. The mod now ships a full-replacement `history/states/00_states.txt` (675 land states, each defined exactly once — 33 Yongchang ledger states plus every other state verbatim from vanilla) and the partial ledgers were deleted. A fresh hidden `none/23` launch after the final correction parsed without Mod errors; visual campaign confirmation remains manual.
- The 15-run / three-seed observation matrix is prepared but remains pending manual UI observation; no long-run statistics are claimed.

Known limits: in-game journal/event execution and balance still require manual 1836 campaign verification, the mod does not change base map geometry, some regional starts use Province subsets, and NMG remains a contested Mexican autonomous subject.
