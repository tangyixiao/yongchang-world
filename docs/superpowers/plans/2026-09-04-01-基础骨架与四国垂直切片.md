# 基础骨架与四国垂直切片 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可验证、可由启动器加载的Mod骨架，并让大顺、靖海、东明、北清四国在1836开局中可选、可进图、具有正确基础关系。

**Architecture:** 游戏目录只承载运行时脚本；`data/baseline`保存1.13.11基线快照，`data/scenario`保存预期事实，`tools/ywc_check.py`比较二者与Mod文件。首个垂直切片覆盖大陆大国、高自治藩国、海外分裂国家和极小岛国四种数据形态。

**Tech Stack:** Victoria 3 Clausewitz/Jomini脚本、JSON、YAML本地化、Python 3标准库`unittest`、PowerShell、Git。

**Spec:** `docs/superpowers/specs/2026-09-04-03-Mod技术框架.md`，并受其余三份世界观/年表/开局规格约束。

## Global Constraints

- 游戏路径固定为`E:\SteamLibrary\steamapps\common\Victoria 3`，版本`1.13.11`，Build ID `24799966`。
- 不修改本体；不使用`replace_path`覆盖整个原版数据库目录。
- 所有脚本键使用`ywc_`前缀；四国TAG固定为`SHU`、`JHG`、`DMG`、`NQG`。
- `JHG`使用原版`tributary`表达高自治，大顺为宗主；自定义Subject Type不进入本阶段。
- `NQG`总人口必须落在30,000—60,000；`DMG`不得拥有马尼拉；`JHG`不得拥有厦门或金门。
- 测试只使用Python标准库，避免把开发环境依赖带进Mod。
