# 《永昌世界》v0.2「六六大顺」实施计划

> **执行方式：** 主执行者 inline 完成；复用清单驱动架构，区域国家保持轻量。

**目标：** 西南六国（丽江 LJG、西双版纳 SIP、德格 DER、嘉绒 GYL、掸邦 SHD、若开 ARA）各得一条核心日志与三个双语事件，把大顺西南边疆做成可玩对局。新增 18 个事件、六个 journal、八个限时修正。

## 文件职责

| 文件 | 职责 |
|---|---|
| `data/content/southwest_event_catalog.json` | 六线 18 事件双语清单（唯一实现输入） |
| `tools/build_southwest_content.py` | 校验清单并生成事件脚本与双语文案；`--check` 模式 |
| `yongchang_world/events/ywc_southwest_events.txt` | `ywc_<tag>.1`–`.3` × 六国 |
| `yongchang_world/common/journal_entries/ywc_southwest_journal.txt` | 追加六条 `ywc_je_sw_<tag>` |
| `yongchang_world/common/history/countries/ywc_regional_countries.txt` | 六国块加 `ywc_reset_shared_variables` + 日志挂载 |
| `yongchang_world/common/static_modifiers/ywc_static_modifiers.txt` | 八个限时修正 |
| `yongchang_world/localization/{simp_chinese,english}/ywc_southwest_keys_l_*.yml` | journal/修正双语键 |
| `tools/ywc_southwest_check.py` + `tests/test_southwest_content.py` | 静态校验与测试 |

## 任务

1. 清单与生成器：六线 × 三节，双语文案逐国成文；生成器校验唯一 ID、线结构、选项数（前两节 2 选项、末节 2–3 选项）、修正声明。
2. journal 与开局挂载：六条 journal 追加进 `ywc_southwest_journal.txt`（脉冲按 marker 链投递）；六国块按"先 reset 后挂日志"补初始化。
3. 校验与测试：可达性计数 305→323 / 80→86；变异测试证明校验器有效。
4. 文档：README/CHANGELOG/验收说明 v0.2 章节（版本重命名同批提交：v1.0「受命于天，既寿永昌」= 天命霸权层）。
