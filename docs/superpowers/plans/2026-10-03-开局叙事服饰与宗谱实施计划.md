# 开局叙事、服饰搭配与四家宗谱实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让所有模组国家选择描述以本国处境问题收尾，为汉人角色提供可靠的可选服饰搭配，并使大顺、东明、新明、明香的现任王室与继承人遵循各自宗谱规则。

**Architecture:** 以 `tools/build_frontier_polity_content.py` 中的中英文风味文本为国家选择文案唯一来源，生成对应本地化。王室人物沿用现有角色模板、国家历史和 on-action 结构；服饰只在 README 中提供自愿安装建议，不复制资产、不增加依赖。

**Tech Stack:** Victoria 3 1.13 Clausewitz 脚本、YAML 本地化、Python 标准库内容生成器、Markdown。

**Spec:** `docs/superpowers/specs/2026-10-03-开局叙事服饰宗谱与法律设计.md`

## Global Constraints

- 所有模组自带国家风味文本均提供中英文版本，并以贴合该国处境的自然问句结束。
- 不把第三方服装资产复制或打包进永昌世界，也不强制玩家安装外部模组。
- 大顺李氏、东明朱氏、新明朱氏、明香朱氏分别成谱；史实和架空支系明确区分。
- 只规范现有王室人物和明确写入模组的继承人，不增加出生、自动继承或随机改名系统。
- 保留已有未提交改动；只暂存本计划涉及的目标文件。

## Review Focus

- 中文问句须以全角问号结尾，英文须以问号结尾；检查生成器来源和生成结果一致。
- 特殊国家和通用国家的所有描述分支都要覆盖，包括单独生成的 MGL 文本。
- 汉人文化角色不能因兼容服饰而被错误改成满族；外部服饰模组仍是可选搭配。
- 四家谱系不得共享同一朱氏字辈；架空字辈不得标成明史原制。
- 只更名目标王室角色，不改同姓将领、其他国家人物和角色文化。
