# 《永昌世界》v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在Victoria 3 1.13.11中交付可从1836游玩到1936的《永昌世界》v0.1，同时实现十个核心内容国、完整区域开局、无DLC基线与DLC增强。

**Architecture:** 项目按“可启动垂直切片→区域场景→国家内容→平衡发行”四个可独立验收的子计划推进。所有游戏脚本位于`yongchang_world/`，Python标准库验证器位于`tools/`，场景事实表位于`data/scenario/`，测试位于`tests/`；事实表负责发现遗漏，游戏脚本仍是运行时真源。

**Tech Stack:** Victoria 3 1.13.11 (Matcha), Clausewitz/Jomini脚本, YAML本地化, JSON元数据, Python 3标准库`unittest`, PowerShell启动与日志采集, Git。

**Spec:** `docs/superpowers/specs/2026-09-04-00-世界观总纲.md`、`docs/superpowers/specs/2026-09-04-01-1644至1836历史年表.md`、`docs/superpowers/specs/2026-09-04-02-1836开局剧本.md`、`docs/superpowers/specs/2026-09-04-03-Mod技术框架.md`

## Global Constraints

- 固定开发基线：Victoria 3 `1.13.11 (Matcha)`，Steam Build ID `24799966`。
- 本体只读：`E:\SteamLibrary\steamapps\common\Victoria 3`；不得修改或复制覆盖本体文件。
- 所有新增脚本键使用`ywc_`前缀；三字母国家TAG除外。
- v0.1不修改底层地图几何，只复用现有Province并拆分State所有权。
- v0.1不重写科技树、不新增大批商品、不改写整个欧美、不预定1900—1950结局。
- 无DLC必须可启动；`ep1_content`、`mp1_content`、`ep2_content`只提供增强内容。
- `MNG`、`TIB`、`KOR`、`LAN`、`EZO`、`KOK`、`SHN`、`LAD`、`MNP`、`ARA`复用原版TAG；新TAG不得与1.13.11本体冲突。
- 新明`NMG`始终是墨西哥的争议自治属邦；北清`NQG`人口保持三万至六万；靖海`JHG`是大顺高自治藩国。
- 每个任务先写失败测试，再写最小实现，验证通过后只提交该任务涉及的文件。
- 实施前不得改变本计划与规格；发现史实或引擎冲突时先更新规格和计划并单独提交。

## 全局完成门槛

- `python -m unittest discover -s tests -v`全部通过。
- `python tools/ywc_check.py --mod-root yongchang_world --game-root "E:\SteamLibrary\steamapps\common\Victoria 3\game"`返回码为0。
- 调试模式启动后，`error.log`中不存在以`ywc_`或本Mod路径为来源的`[pdx_assert]`、`[jomini_script_system]`、`Unknown trigger/effect`、缺失TAG和缺失本地化错误。
- 无DLC、三种单DLC和全DLC五种配置均能选国并进入1836。
- 十个核心国均能完成或失败其主日志，不存在永久不可达分支。
- 至少三次不同随机种子的1836—1900观察局无开局十年系统性崩溃。
- 工作树干净，发行提交有版本号、变更记录和已知限制。
