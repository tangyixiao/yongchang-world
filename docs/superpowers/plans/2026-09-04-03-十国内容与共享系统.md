# 十国内容与共享系统 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为十个核心国家补齐共同的“谁承中华？”框架以及各自的主日志、辅助日志、事件、长期路线、AI权重、动态国名和旗帜。

**Architecture:** 共享系统只提供可复用触发器、效果、修正和本地化；国家文件只消费这些接口，不互相复制整套事件。每国拥有一份内容清单，静态测试按清单核对主日志、分支、事件数量、路线和本地化，防止“有文件但不可玩”。

**Tech Stack:** Victoria 3 1.13.11 Journal Entry/Event/Interest Group/Ideology脚本、动态国名与旗帜、Python标准库测试、YAML本地化。

**Spec:** `docs/superpowers/specs/2026-09-04-00-世界观总纲.md`、`docs/superpowers/specs/2026-09-04-02-1836开局剧本.md`、`docs/superpowers/specs/2026-09-04-03-Mod技术框架.md`。

## Global Constraints

- 核心国家固定为`SHU`、`JHG`、`DMG`、`NQG`、`OIR`、`MNG`、`TIB`、`KOR`、`LAN`、`NMG`。
- 每国至少一条主日志、二至四条辅助日志、八至十五个事件、两条长期路线、AI权重、动态国名或政体变化、国旗和国家特质。
- 事件不能自动授予整个中国核心；海贸只产生商业、财政、造船和知识优势，不直接触发工业革命。
- `SHU`不是清帝国继承者；`JHG`不被低成本吞并；`NQG`不获得大国人口；`NMG`不得脱离墨西哥属邦关系直接变成美洲大国。
- 所有事件ID、日志ID、变量、修正和本地化键使用`ywc_`前缀。
- 所有路线必须有成功、失败和放弃后的可玩状态，不能依赖隐藏的永久条件。
