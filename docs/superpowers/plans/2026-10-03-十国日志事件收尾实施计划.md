# 十国日志与事件内容收尾实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成十个主线国家既定日志与事件内容，补齐中英文、触发入口和结局文本，同时保留已有 ID 与外交/路线边界。

**Architecture:** 以已批准的 2026-09-25 十国事件卡和跨国危机卡为内容来源，沿用 `large_campaign_event_catalog.json` 与 `build_campaign_content.py` 的生成结构；只补齐缺项，不重写现有日志、事件 ID 或用户正在编辑的剧情机制。

**Tech Stack:** Victoria 3 Clausewitz/Jomini 脚本、YAML 本地化、JSON 内容目录、Python 标准库生成器。

**Spec:** `docs/superpowers/specs/2026-10-03-开局叙事服饰宗谱与法律设计.md`；内容细则：`docs/superpowers/specs/2026-09-25-大型内容包十国事件卡.md`、`docs/superpowers/specs/2026-09-25-大型内容包跨国危机事件卡.md`。

## Global Constraints

- 先完成既定日志与事件内容，再更新十国开局法律。
- 保留现有日志 ID、路线 ID、事件 ID 和共享变量接口。
- 中英文同时补齐；事件选项必须呈现真实收益、成本和失败结果。
- 不借事件自动授予长期领土、免费工业化或绕过既定属邦关系。
- 保留已有未提交改动；只暂存本计划涉及的内容文件。

## Review Focus

- 日志月度脉冲必须只在正确国家触发，路线启动/失败/放弃清理条件不能互相冲突。
- 每个触发事件必须存在且入口可达；事件结果必须回到预期日志或结束标记。
- 中英文事件标题、描述、选项和日志理由须逐条齐全且互相对应。
- 经济或外交后果必须匹配对应国家，不能错误改动其他国家、领土或宗主关系。
- 危机事件的国家限制、停战条件和防重复触发逻辑须与既有路线一致。
