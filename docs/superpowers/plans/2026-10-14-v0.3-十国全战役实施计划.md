# v0.3 十国全战役实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成十国九条长线，至少720新事件和180新日志，覆盖三时期且让前序选择持续生效。

**Architecture:** 复用已验收管线与生命周期，按国家拆分明确内容清单。先以三个改革国家证明玩法，再扩展海贸、边疆核心国；各时期使用依赖关系与真实国情接续。

**Tech Stack:** 既有v0.3 JSON schema、Clausewitz、双语本地化、unittest和离线脚本回归。

**Spec:** 同日完整设计；同日十国长线内容目录的90条命名长线与三条详细卡。

## Global Constraints

- 总计划与子计划一接口全部适用，每国≥72新增事件/18新增日志，三时期各三条命名线。
- 各时期约定内容密度，不以到年份强制改革、战争、共和或工业化。
- 首批示范事件属于对应国指标，不再重复新增或计数。
- 旧路线与霸权结果接口保持兼容；国别专属效果不可由通用正负分替代。

## Review Focus

- 早期财政或身份协议被后期无视：Task 4的跨期矩阵必须读取早期outcome。
- 保守/改革失败导致后期无内容：每国测试保守与受挫通路。
- 君主制与共和制切换使人物失效：按当前职务或集团接续，不复活已故角色。
- 法律已提前通过仍要求重复成本：每线提前满足情景。
- 互斥支线在同一局都启动：每国清单检查条件与运行回归。

## 一、文件与分工

每国主输入固定 `data/content/v03/countries/<tag>.json`，其中tag使用小写运行标签（MGL文件为mgl.json，legacy_namespace仍ywc_mng）。相应生成输出遵循子计划一 `<key>=country_<tag>` 规则。每国独有手工效果/条件分别写 `common/scripted_effects/ywc_v03_<tag>_effects.txt` 与 `common/scripted_triggers/ywc_v03_<tag>_triggers.txt`；放在 `yongchang_world/` 下。

测试固定 `tests/test_v03_<tag>_content.py`。共享文件单一代理维护；多国作者只修改本国文件。国家注册进入manifest/id_registry由整合代理完成。
