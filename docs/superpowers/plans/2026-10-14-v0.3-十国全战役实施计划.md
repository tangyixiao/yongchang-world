# v0.3 十国全战役实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成十国九条长线，至少720新事件和180新日志，覆盖三时期且让前序选择持续生效。

**Architecture:** 复用已验收管线与生命周期，按国家拆分明确内容清单。先以三个改革国家证明玩法，再扩展海贸、边疆核心国；各时期使用依赖关系与真实国情接续。

**Tech Stack:** 既有v0.3 JSON schema、Clausewitz、双语本地化、unittest和离线脚本回归。

**Spec:** 同日完整设计；同日十国长线内容目录的90条命名长线与三条详细卡。

## Global Constraints

- 总计划与子计划一接口全部适用，每国≥72新增事件/18新增日志，三时期各三条命名线。
- 各时期约定内容密度，不以到年份强制改革、战争、共和或工业化。
- 首批示范事件属于对应国指标，不再重复新增或计数。
- 旧路线与霸权结果接口保持兼容；国别专属效果不可由通用正负分替代。

## Review Focus

- 早期财政或身份协议被后期无视：Task 4的跨期矩阵必须读取早期outcome。
- 保守/改革失败导致后期无内容：每国测试保守与受挫通路。
- 君主制与共和制切换使人物失效：按当前职务或集团接续，不复活已故角色。
- 法律已提前通过仍要求重复成本：每线提前满足情景。
- 互斥支线在同一局都启动：每国清单检查条件与运行回归。

## 一、文件与分工

每国主输入固定 `data/content/v03/countries/<tag>.json`，其中tag使用小写运行标签（MGL文件为mgl.json，legacy_namespace仍ywc_mng）。相应生成输出遵循子计划一 `<key>=country_<tag>` 规则。每国独有手工效果/条件分别写 `common/scripted_effects/ywc_v03_<tag>_effects.txt` 与 `common/scripted_triggers/ywc_v03_<tag>_triggers.txt`；放在 `yongchang_world/` 下。

测试固定 `tests/test_v03_<tag>_content.py`。共享文件单一代理维护；多国作者只修改本国文件。国家注册进入manifest/id_registry由整合代理完成。

### Task 1：前期国内改革三国扩写

**Files:** SHU/DMG/KOR三个catalog、独有脚本、生成输出与对应测试。

**Interfaces:** 消费三条示范线及目录三国前期其他6线；产出三国前期9线，最低72事件18日志（含已完成示范），不依赖未实现中后期。

- [ ] 逐国为目录每线新增六类动态用例，并为两种策略断言支持/反对集团与资源要求确实不同。
- [ ] 把目录中命名线展开成明确event/journal记录，写双语、条件、实际行动、失败与退出；关键选择至少两个后续读取。
- [ ] 运行 `python -m unittest discover -s tests -p "test_v03_shu_content.py" -v`，DMG/KOR同样执行；未知引擎条件先对本机官方脚本核对并登记，不能编名字。
- [ ] 生成并执行新检查、总可达性；独立审查三国原文与脚本，修复后逐国提交。

### Task 2：其余七国前期内容

**Interfaces:** 同一schema/lifecycle；产出七国前期21线至少168事件42日志，与Task1合计30线240/60。

- [ ] 测试每国有三条前期线，且至少分别读取国内组织、资源供给、外部关系中的实际条件；国家消失及伙伴拒绝有收束。
- [ ] 按JHG/LAN/NMG→NQG/OIR/MGL/TIB顺序写各国内容；每个国家完成即独立验收，防止等七国都写完再发现接口错误。
- [ ] 各国定向测试使用固定文件名模式；执行生成器check、新校验和总校验。
- [ ] 检查与旧路线对接、MGL/ywc_mng别名、库页NQG与外贝加尔CHI身份差别；修复后逐国提交。

### Task 3：十国中期的制度后果与社会变化

**Files:** 十国catalog的middle期、独有脚本/输出/测试；Create `tests/test_v03_cross_era.py`。

**Interfaces:** 读取前期线显式outcome与当下国情；每国中期三线，累计60线480事件120日志。跨国危机结果未就绪时读取明确的“未发生/未参与”分支，不能引用缺失变量。

- [ ] 为十国各写至少确立/妥协/受挫三种早期结果×中期入口测试，以及未工业化、长和平、保守法制三类替代语境。
- [ ] 按目录展开中期角色、劳资与代表、投资及地方/中央关系；影响既有法律和真实集团，避免把新制度写成无成本授予。
- [ ] 每国完成后生成、定向测试、内容审查；最后运行 `test_v03_cross_era.py`，两种前期选择应使至少两个中期节点或条件不同。
- [ ] 与危机计划集成，并记录各国中期离线情景、数量与不支持的引擎效果。逐国提交。

### Task 4：十国后期与全世纪接续

**Files:** 十国catalog的late期、独有脚本/输出/测试；Modify `tests/test_v03_cross_era.py`。

**Interfaces:** 每国最后三线；十国90线达到720/180。读取中期制度、伙伴、移民或社会关系；世界主题缺席时仍有国家自身后续。

- [ ] 写跨期测试：提前发展可提前进入；未工业化国家到1900仍有相称内容；改政体后职务承接；战败/失州/换宗主不复原旧秩序。
- [ ] 根据目录写大众政治、社会保障、身份与动员等适用内容，并写和平发展、保守整合和区域合作分支。
- [ ] 每国至少检验一条前期决定通过中期读取到后期，保留三类结局及补救路径；主题层不替代本国收束。
- [ ] 十国定向测试、新生成器check、数量清点与跨期回归全部通过后提交；实机明确未执行，静态计数不能升级运行状态。
