# 《永昌世界》v1.0「受命于天，既寿永昌」先行层实施计划

> **执行方式：** 主执行者 inline 完成；复用大型内容包的清单驱动架构，不另起炉灶。

**目标：** 在三章战役结算后的天下，落地可玩的天命霸权层：大顺颁行朝贡新制，九国各自抉择，顺者得互市与保护，逆者承受孤立与倾覆之危；霸权权威不足则新制受挫或崩解。新增 33 个双语事件与 6 个限时修正。

**架构：** 新清单 `data/content/hegemony_event_catalog.json`（唯一实现输入）→ `tools/build_hegemony_content.py` 生成 `ywc_hegemony_events.txt`（霸权线 6 + 九国各 3）与 `ywc_hegemony_l_*.yml` → `ywc_hegemony_effects.txt` 阶段推进（字面事件引用）→ 触发钩子由生成器写入 `ywc_shu.114` 结算选项与 `ywc_crisis.6` 全协议选项（生成器重新生成大型内容包产物时保留此钩子）。`tools/ywc_hegemony_check.py` 与 `tests/test_hegemony_content.py` 守门。

## 实施任务

1. **清单与生成器**：33 事件双语（九国 `.200` 诏使至国按各国第三章处境单独撰文；`.201` 顺者之昌、`.202` 逆者之亡各自成文）；生成器校验唯一 ID、参与国、选项数、双语覆盖、修正与代价，`--check` 校验漂移。
2. **推进效果与修正**：霸权阶段机器（颁诏→应答期逐季投递→酬顺→问逆→朝会→天命结算）、`ywc_tribute_answer` 记录、`ywc_hegemony_authority` 0–100 维护、六个限时修正注册与双语。
3. **触发钩子**：`ywc_shu.114` 制度确立选项与 `ywc_crisis.6` 全协议选项写入霸权启动块（正统性 ≥60、四个参与国存续、互斥标记）；由大型内容包生成器输出，保证两包产物一致。
4. **校验与测试**：霸权校验器（33 唯一 ID、九国投递、三态结算、修正声明、双语键）+ 单元测试（清单不变量、生成器拒绝路径、变异测试）；可达性计数 272→305 / 79→80。
5. **文档**：README v0.2 章节、CHANGELOG 条目、验收说明更新（静态通过 ≠ 实机验收）。
