# 大顺军费：接入军制与任用线

税册线已记录中央分期、预算排队和地方承担者，但下一条军制线尚未读取这些决定。本批让已有地方税权在两次实际选择中产生可核查的费用差异，并让专业路线的继任观察读取已到期军费是否真实付清。

- 只有税册记录承担者为地方（3）且仍有地方查核权，军镇共约才可沿用既有地方报告权，免收原本的中央核验费；签约时同时记录地方参与，而非生成地方现金。缺少任一条件、旧存档没有标记，均沿用原收费或其他既有优惠。
- 后续地方转运选择同样可沿用该既有权利，免去原中央协调费用；以独立“免收”记录表示，绝不写“已付款”。没有该承诺的路径仍须按原收费和现款条件执行。各选项与效果执行期均重检，不能重复收费或将免收写成付款。
- 专业军制的继任审查在已签中央军费合同且存在到期未付时不能持续观察或按专业路线成功；损坏的活跃账本也不能被当作已结清。其他无新合同的旧存档保持原行为，未到期但已按期付款的合同不受阻。玩家仍可修复欠期后重新观察，或选择有限旧军/撤回；不得宣称代表军人 POP 已收到工资。
- 使用真实税册到军制的源码队列，比较地方承担与预算排队在相同后续选项中的费用/权利，覆盖欠期、付清、损坏账、旧存档、重复效果及审查中断。同步双语说明、生成与适配器检查；仅离线验证，不启动游戏。

实际期限、同回调现金余额刷新、AI 与存档行为仍需引擎验收。商垫与后续海关的真正承接另列，不在本批冒认完成。
