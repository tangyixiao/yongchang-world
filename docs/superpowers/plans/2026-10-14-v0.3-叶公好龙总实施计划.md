# v0.3「叶公好龙」总实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成贯穿 1836—1936 的四层日志事件内容，新增至少 1290 个事件和 342 个日志，并取得静态检查与离线脚本回归证据。

**Architecture:** 以本体真实政治经济状态驱动国家长线，配套行动日志、条件事件和国内外后续；国家、区域危机、63 个非十国政体与跨国主题分别拥有内容清单。用户已明确本轮不做实机验证，禁止启动Steam、游戏或操作游戏UI。新内容采用独立的 JSON 输入和确定性生成文件，保留旧 ID、变量和路线结果接口。

**Spec:** `docs/superpowers/specs/2026-10-14-v0.3-叶公好龙设计.md`；同日十国长线目录、区域危机与边疆目录。

## Global Constraints

- 机制后果 > 故事 > 引导；国内改革 B → 宗藩海贸 A → 边疆 C；时间依次铺设 1836—1870、1870—1900、1900—1936，实际触发读取国情。
- 十国 90 线至少 720 新事件/180 新日志；8 危机至少 96/24；63 非十国至少 378/126；12 跨国主题至少 96/12。合计至少 1290/342，旧内容不抵新增。
- 单线至少两种成立的策略与确立、妥协、受挫收束；重要选择至少两个后续节点读取。
- 保留旧 ID、标签、地图、人口和开局法律；MGL/RKN 为运行标签，MHG 与 NMG 分开，CHI 与 NQG 分开。
- JSON 无 BOM、游戏本地化 UTF-8 BOM；中文英文同步；新生成器只拥有自己的输出。
- 主线季度间隔、常态风味月度上限、跨危机季度冷却、主动长线最多三条/可见任务最多六条；特殊紧急事件逐项登记。
- 国家长期汇总数值每国新增最多两个；先用实际法律、经济、集团和外交，不制作独立经济模拟。
- 内容分批可运行，不能用随机模板、同一套增减分或纯通知填补内容数量。
- 用户已要求完成计划后直接以 subagent 团队执行；代码由 Luna 优先实现，主代理负责方案、接口、复核和离线验收；实机验证明确不在本轮范围。

## Review Focus

- 新旧推进来源并存：新线启用后旧脉冲不能重复事件、费用或奖励；由子计划一 Task 3 回归。
- 国家灭亡、易主、宗主变化与战争：以当前国家关系改道，不能恢复旧疆域；由子计划二和三各批动态用例回归。
- 提前改革、反向改革与长期保守：三种战局均可读、有后续；由子计划二的每国用例回归。
- 旧生成器国家排序变化：既有 168 个边疆事件不重排；由子计划一 Task 1 的映射变异测试回归。
- DLC 缺失、内容数量充足但关键线不可达：基础故事仍可走，数量和有效可达性分别检查；由子计划三的 profile/发布测试回归。
