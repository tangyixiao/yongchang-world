## 全局约束

1. 质量顺序为**实际机制后果 → 故事 → 引导和节奏**。推进优先级为国内制度与改革 → 宗藩和海贸 → 小国与边疆，先开局、中期，再覆盖后期。
2. 当前用户没有授权实机操作：**不要启动 Steam、游戏、启动器或游戏 UI**，不执行真实存档、AI、自然战局、游戏性能及平衡测试。安装目录下的脚本/二进制可以只读检查；如后续用户明确另行授权，另立验收记录。
3. 不自动合并 PR、不发布或制作版本发布物；实质工作按可独立审查的范围开草稿 PR。不要为了增加 PR 数重复提交同一功能。
4. 保护所有已有未提交与未跟踪文件。禁止对工作树执行 `git reset --hard`、`git clean`、强推或覆盖式同步；先核对分支、内容、重叠和哈希，只暂存明确属于本任务的文件。
5. 不把一个旧 ID 换名、多个翻译、选项或纯重复通知算成新增事件；不把只有标题差别的空日志计入日志。保留旧 ID、旧变量与既有结果，重大结果由已兑现的行动产生。
6. 双语同批完成；游戏 `.txt`/`.yml` 按仓库格式使用 UTF-8 BOM，JSON 使用 UTF-8 无 BOM。先核对文件的现有编码及 Git 换行规则，不以全文件格式变化掩盖内容变化。
7. 外部模型或工具失败后不自动重试、换账号或暗中换提供商；保留已写文件和错误证据，再根据用户授权与本机实际能力选择明确的后续工作。不得把 `completed`、模型自述或计划中的测试当成实际代码和通过结果。

1. **对象与时间：**实际捕获的国家、州、岗位、合同代次在期间变化或消失；不得换成同地区另一个对象，已签债务不得凭空消失。

5. **极端与兼容：**国家灭亡/新生、失州、转主、战争、破产、无伙伴、少 DLC、旧档三种状态、长期和平或保守路线；都须有诚实的继续、缩限或退出。

#### 1. 范围与计数

十国各安排九条长线，共 **90 条命名长线、至少 720 个新增独立事件、180 个新增日志**。下表每条线的“事件/日志”是已分配的最低生产预算，各国均为 72/18；新增分支超过预算可以保留。已存在事件的改名、重复通知、同一事件不同选项、翻译条目和通用可重复弹窗不计入新增独立事件。把一个既有日志拆成几个无独立目标的壳条目，也不能据此达成新增日志预算。

预算不要求每条线都采用八事件、两日志的结构：本目录实际使用 6、8、10 个事件及 1、2、3 个日志的组合。日志必须有可操作目标，事件必须有独立矛盾、参与者行为、局势回应或结果。新增预算之外，旧三十章继续接受盘点、重写、去重与承接修补；旧内容不能冒充新增内容。

实施顺序是 **SHU、DMG、KOR → JHG、LAN、NMG → NQG、OIR、MGL、TIB**，三组都覆盖全战役。每国的“奠基、扩展、韧性”是议题层次：通常在约 1836—1870、1870—1900、1900—1936 集中出现，但由实际局势、前序结果与国家能力开启，不能按年份强迫转型。未工业化、保守延续、改革撤回、国家衰退、长期和平都有后续。实际战争发生时再使用动员分支，不预定战争、共和、独立或工业化。

#### 2. 全目录共同规则

- 每行“真实行动/状态”必须接入法律、政府组成、集团力量、机构、建筑就业、生产方式、预算、商品供给、市场接入、实际外交关系等游戏事实。少量专属状态记录承诺、契约、例外和结果，不能另造一个分数替代真实治理。

##### 6.1 SHU《天下田粮，谁家账册》

**设计标识**：`v03_shu_fiscal_register`。事件锁定 `ywc_shu.1000`—`.1009`；两 JE 键为 `ywc_je_v03_shu_register_pilot`、`ywc_je_v03_shu_fiscal_settlement`。登记后先查重，不能覆盖既有 `ywc_shu.100`—`.114`。下表 E1—E10 依次对应 `.1000`—`.1009`。

**参与者**：户部官员要可核账收入；地方缙绅要认可供役与旧免；军镇要先领欠饷；海商愿预付但要求稳定税则；被重复征役的民户要可申诉。集团不等同于所有本地人口，事件具体承担者按实际州就业和集团映射选取。

**入口与已有内容**：SHU 存在且拥有至少一个可执行行政的州，尚未完成此线；由旧朝廷三席内容提出，或玩家主动开启。现有税法和官僚体制先进时，以《已经在册的田粮》替代开场段落并进入执行审查，不能要求倒退法律重做。只存一个试点州 scope；州丢失时保留承诺并允许选新州，已付不可退的清查费用仍保留。

**JE 1《把田粮写进同一本册》**：玩家在自己拥有、未被占领的州里选择试点；目标是补足行政与供给、确定查核/地方分担方式，并完成两次相隔至少三个月的核账。首版门槛采用试点官署就业率 ≥80%、纸张投入品无短缺、全国行政余额 ≥0；若开局缺少官署或相关投入，则建设与采购本身是实际目标。清查新增官署不是强制数量，已有能力能直接满足。地方合作路线可以用较低中央覆盖换分税义务，不能用按钮直接消除真实税收浪费。

**JE 2《新税册要付旧承诺》**：JE 1 有分类结果后开启；检查税册是否被用于军饷、地方供役或商税替代。玩家为试点划定中央查核、地方分担、旧额封顶之一，维持六个月可支付预算与执行能力。财政观察中“可支付”定义为未破产、未违约、债务负担比（本体 `scaled_debt`）未连续三个月增加；不是必须国库全满或全国零税收浪费。这里观察的是债务相对限额的压力，不能声称测得绝对债务额的变化，也不用单月固定净收入为负直接代替三月观察。战时可改为有限核账并留下延期，不强迫停战。

**专属记录**：查核模式三选一；试点州；承诺的补偿/分税有效期；延期原因；结果为中央核账、地方分担、有限旧额、撤回失信之一。真实税收、建筑与法律不复制成进度分数。费用按开启时的周财政收入折算：一次清查为一周收入，分两次扣付；地方补偿为十二个月合计两周收入。若引擎无法直接读取该口径，实施者先用现版官方脚本支持的收入基数确认并登记，不能悄悄换成各国相同的固定金钱。

##### 6.2 DMG《共同臣民的名字》

**设计标识**：`v03_dmg_common_subjects`；事件锁定 `ywc_dmg.1000`—`.1009`；两 JE 为 `ywc_je_v03_dmg_public_qualification`、`ywc_je_v03_dmg_compact_review`。本线重写既有《共同臣民》《法律上的本地人》的承接时，旧事件只是前序或跳转，不计入这十个新增定义。下表 E1—E10 依次对应 `.1000`—`.1009`。

**参与者**：朱氏王廷要可征税、可守边界的共同忠诚；明裔军户要求旧服役地位获承认；华商要稳定契约和任官渠道；本地贵族要地区权利；村社和混合家庭要不受任意排除的税务、军职与申诉资格；宗教团体关心公共仪礼和教育。不能把任何一方简单写成整种文化的唯一代表。

**入口**：DMG 拥有北吕宋至少一个州且存在实际多群体政治/身份矛盾，旧契约线已引入或主动开启。相关法律提前改变时，转入落实和任命争议；仅改变政体不自动完成共同资格。若只剩单一文化或缩小到无法呈现原矛盾，保留法律审查与迁入者资格，改写事件参与者。

**JE 1《同一国书上的资格》**：玩家选择一项首轮行政职责（官署、军职或地方税务）作为执行入口，在六个月内形成共同资格或地区保障条款，并使相关岗位实际就业、行政不赤字。国籍/身份读取现版 acceptance、实际任官/从军和政治资格，不能假定某个旧版国籍法等于完全平等。本机官方当前 `00_citizenship.txt` 含 `law_subjecthood` 和 acceptance 机制；实现必须核验其正式触发与可获取数据，再冻结检测定义。

**JE 2《共同义务是否兑现》**：第一份契约有结果后开启九个月审查。共同资格路线必须在法律上允许约定群体从军/任官，且落实官署/军队岗位；地区契约路线不要求全部相同，但须有实际地方执行和双方可用的申诉机制；旧身份路线须公开区分资格并付出安抚与额外分治行政成本。政治代表方面，依法有选举则检查资格与实际代表制度；无选举的咨询王权采用公职资格和共同任命章程，不虚构议会选票。

**费用与兑现**：双语登记/申诉所十二个月合计一周开启时财政收入，并占用行政能力；旧军户补偿十二个月合计一周收入；任官与军队目标依真实建筑就业与法律，无免费官员。三条路径互斥记录 `common_qualification`、`territorial_compact`、`status_orders`，可经后续重议改变。接纳程度和就业是不同事实；有新法而没岗位，不能写“已进入官署”。

#### 3. 跨国主题层：12 组、96 个新事件、12 个新日志

##### 4.0 每国六事件如何贯通世纪

每国增加两个专属日志 A/B、六个专属事件 E1—E6，下表按早期/中期/后期各列两个标题。A 主要处理地方基础与义务，中期转入执行复核；B 读取 A 的结果，再处理外部依赖、社会变化和制度继承，后期可更新阶段。年份是内容铺设的参考区间：早期约 1836—1870，中期约 1870—1900，后期约 1900—1936；触发读取实际局势和前序结果，不用硬日期强制国家完成工业化。

后期的第六事件须有多种可继续结局：制度巩固、限额妥协、撤回/失败、保留旧约。没有现代工业或大众政治时，以原有地方制度的代际争议和预算持续性收束；不把“没走改革路线”解释为无内容。继承人、议事代表和社群发言人的使用以实际人物功能可实现为准，可用职务角色承载，不能把历史名人固定活到 1936 年。

**ID 与 manifest 合同**：按下表 F01—F63 固定国家顺序，第 n 国分配 `ywc_regional.[1000 + (n−1)×100]—[1099 + (n−1)×100]` 的 100 槽位。最低六个新事件依 E1—E6 占该国槽位的 +0—+5，剩余槽位供扩展，不计入交付。两个新日志分别为 `ywc_je_v03_<小写tag>_a/b`；A/B 的标题依表填写。F01 为 `.1000—1005`，F63 为 `.7200—7205`，总保留范围 `.1000—7299`。旧 `ywc_frontier.*` 与西南六国事件 ID 不变，逐个登记沿用、修订或退出入口，均不抵扣新增六事件。

最后一列是**玩家实际行动 → 分支后果 → 因果接线**。政策、建设、预算和外交均须落实到当前支持的本体动作或经核验的有限承诺，不能只做分数和三年修正。所有国的拒绝/有限路线都有可完成结局，不要求支付列强规模的成本。

#### 5. 小国预算、后果与退出

1. **预算按国力计，不按国家模板收费。** 以过去可读取期的收入/国库/财政压力测算有限投入，先确认可安全读取的量。最低维护不超过该国可负担的短期财政规模；缺钱时出现延期、缩项目、季节互市或以更少行政任务替代，不创建永久负数支出。最终系数由离线边界用例和静态规则审查确定，不能把列强的固定英镑数复制给环礁或山村国家。
2. **劳力与现金都要解释承担者。** 折役并不凭空增加产出，包税/承包留下监督与利益后果。小国不以拥有铁路、远洋舰队、几十营常备军或完整工业链作为全部结局的必需条件。
3. **承诺分层。** 先可做的单案、单港、单段、季节安排；达到实际能力才可扩为多国常设机构。多边谈判失败后，只要双方另行同意仍可达成较小协议。
4. **退出在签字前就可见。** 日志显示付款范围、有效期、未解决问题和退出代价。主动限缩保一部分权利而牺牲一部分收益；不能把拒签写成无限动乱、必然战争或自动丧失独立。
5. **失败可继续。** 财政恶化、战争、港口失去、国家灭亡、主体变更或伙伴拒绝，及时取消未发生费用，结清有凭据的已有义务，结束失效回调；不得恢复旧主、追溯扣费或向无关继承国自动强加条款。
6. **保守和长期和平也有后续。** 第五、第六事件检查旧制度如何延续、如何调整公共责任与代际地位；不能只有工业化/革命路线才解锁后期内容。
7. **修正不能代替结果。** 临时修正用于过渡、准备或有限余波；核心结果通过真实政策、建设、财政、集团、人口待遇和可用外交机制表达。技术不支持的结果要改成可验证的有限安排，并在玩家文本准确说明。

#### 6. 实现拆分与因果接口

区域内容按上述九组 catalog 分批，每个国家都有完整字段：tag、已存在入口、两个新 JE、六个新事件、时代/阶段、前序结果、参与者、实际可执行动作、他方回应、重复/限时规则、结局和后果、中文/英文键、离线场景。建议文件分组为 `v03_regional_northeast`、`steppe`、`tarim`、`central_asia`、`plateau`、`southwest_frontier`、`ocean`、`southwest_core`、`mekong`；最终路径由实施总计划指定，目录的 F 序号和数量不随拆文件改变。

危机与主题按 C/T 编号各自注册：**C01—C08 分别使用 `ywc_crisis.1000—1099` 到 `.1700—1799`，各线最低新事件占 +0—+11；T01—T12 分别使用 `ywc_society.1000—1049` 到 `.1550—1599`，各组最低新事件占 +0—+7。** 每场危机三个新日志、每组主题一个新日志拥有独立且唯一的键。保留槽位不算已交付事件。

每条接线的发送者和接收者都写入 manifest：例如 SHU 地方税制落实 → HXI 审饷事件资格变化 → HXI 接受/限额/拒绝 → SHU 收到可观察的汇缴与政治反馈；LAN 劳工改革 → WBK 对合同的回应 → JHG 护航/运输预算变化；TIB 教育和宗教供养 → DER/AMD 独立接受或自编教材 → TIB 的供养与权威争议。不得只用同一个“改革分数”在三国加减。

先核验本体法律、政治、建筑、财政、贸易/市场、人物、外交/主体等接口。地图和经济体系保持当前来源，不增科技树、商品体系或全世界通用的大型独立机制；国家专属记录用于存储承诺和前因，不复制一整套脱离本体的分数治理。

#### 三、内容结构与长期发展

以下结构与配套内容目录共同指导新增内容。每条线保留自己的矛盾、行动和结局，事件数量允许在总量下限内灵活分配。

##### 3.1 国内制度与改革

第一批深化大顺朝廷、东明华菲契约与朝鲜改革；随后扩展十国其他国内线，与宗藩海贸及边疆内容接续。

一条改革故事线可由多个相互承接的日志构成：问题浮现、形成支持联盟、选择方案、试办或筹备、实际推进、反对力量回应、执行审查、制度调整及长期余波。不同阶段根据真实局势进入，长度由故事需要决定。

增加内容的重点包括：

- 同一改革涉及的宫廷、官僚、军队、地方、商人和其他社会力量拥有不同诉求。
- 玩家通过法律、建设、预算和政治安排推进改革；事件记录承诺，并检查执行情况。
- 反对者可以谈判、分化、要求补偿或强化抵制；支持者在改革推进后也可能提出新要求。
- 改革的成功、局部落实、延期、撤回和失败分别拥有反馈与后续目标。
- 法律或经济条件已提前满足时，故事承认玩家此前的行动，并转入相应的执行和后果内容。

##### 3.2 宗藩与海贸

以大顺、靖海、兰芳为主要交互节点，并接入东明、新明及实际参与国；具体线索、对手与回应见两个配套目录。

扩充重点包括谈判前的国内立场、各方报价、承诺兑现、局势变化后的调整，以及履约或违约对不同国家的影响。对方国家应能依据自身处境回应；玩家可以选择缩小承诺、重新谈判或承担冲突后果。

##### 3.3 小国与边疆生存

覆盖北清、草原与高原核心国，以及现有独立内容的 63 个非十国政体。56 个边疆政体、6 个西南政体与明香 MHG 分别登记，互不重复。

扩充重点包括地方关系、财政与补给、商路、安全保证、外部依赖和内部争议。不同国力应产生不同选择，有限妥协与退守也应有可继续发展的内容。

##### 3.4 增加内容的层次

| 层次 | 用途 | 应带来的新增体验 |
|---|---|---|
| 主线日志 | 描述阶段矛盾和较长期目标 | 玩家持续处理一组有因果联系的问题 |
| 配套日志 | 承接具体的筹资、试点、谈判或地方问题 | 同一主线拥有多个可以实际着手的任务 |

#### 四、故事线的质量检查口径

每条重点故事线设计时登记：

- 核心矛盾与参与者各自的目标。
- 入口及前序关系，哪些条件依赖真实游戏状态。
- 玩家可以采取的实际行动，以及不同选择的收益、成本和承担者。
- 后续事件读取哪些决定，何时检查兑现，哪些外部变化会引发改道。
- 成功、妥协、失败与主动退出的后续内容。
- 对日志、路线、危机和其他国家的影响。
- 中文与英文文本、玩家可见的条件和结果说明。

全量盘点按国家与系统登记现有内容、玩法缺口、深化优先级和拟增内容。重点线在完成设计后另列静态、实际推进和长期观察的验收要求。

#### 五、内容规模与计数合同

| 层级 | 覆盖 | 新增长线或主题 | 新增事件下限 | 新增日志下限 |
|---|---|---:|---:|---:|
| 十国长期内容 | 十国 × 三时期 × 三条线 | 90 | 720 | 180 |
| 区域危机 | 既有五场深化并新增三场 | 8 | 96 | 24 |
| 非十国政体 | 56 边疆 + 6 西南 + 明香 | 63 | 378 | 126 |
| 跨国社会与时代主题 | 十二组有条件的世界回应 | 12 | 96 | 12 |
| 合计 | 四层互相接线 | 173 | **1290** | **342** |

十国各至少 72 个新增独立事件、18 个新增日志，九条长线各建议 6—12 个事件，国别总量须达标。危机各至少 12 个新事件、3 个新日志；非十国政体各至少 6 个新事件、2 个新日志；跨国主题各至少 8 个新事件、1 个新日志。这些是实际新增定义下限，既有 491 个事件和 162 个自定义日志不抵扣新增目标。

按保留全部旧定义计算，目标至少为 1781 个事件、504 个自定义日志定义。另有一个原版 `je_warlord_china` 覆盖，不计入自定义新增数。该算式表示文本规模，不表示某一局会看到全部内容。

分支共享同一事件定义时只算一个；新增选项、翻译、重复调用、改名、纯转发通知和模板替换国家名均不增加独立事件数。配套日志须有自己的实际目标、阶段反馈和结束条件；只有标题变化的镜像条目不抵数量。旧内容如果因重复被停用，仍保留 ID 并在审计表说明运行入口变化。

目录和清单分别记录“已设计、已实现、静态通过、实机通过”，只在真实证据存在时提升状态。达到总量但缺少有效分支、行动或后果的批次不能验收。

#### 六、机制与世界线边界

##### 6.1 本体系统与国家特色

主要读写本体已有的法律、利益集团、政治运动、建筑就业、识字与教育、市场、财政、外交和战争状态，并继续使用现有正统性、海贸、自治与十国特色状态。

新增状态以命名的承诺、政策、阶段、人物关系和已付成本为主。每国最多新增两个长期汇总数值；每个数值须有可见解释及真实状态读取，不能成为又一套通用改革分数。阶段计时与一次性标记不计入该上限。首批不增加全局货币、独立经济模拟或大规模自定义 UI。

事件可以支持、阻碍或提出立法，实际制度完成仍检查当前法律和执行能力。国家更换政体或走保守路线后，相关后续继续可用。土地、主权、条约和属邦关系由游戏支持的合法行动改变；普通事件不赠送领土、全域核心、无条件独立或免费工业化。

##### 6.2 国别身份与地理来源

运行标签使用 MGL、RKN；原有 `ywc_mng` 命名接口保留。明香 MHG 按湄公河华人政体处理。CHI 是当前资料中的外贝加尔大清残廷，与库页北清 NQG 区分。

盘点先纠正文本与实际地理错位：HSR 为希萨尔、DRZ 为达尔瓦兹、BKY 为布克依、LXJ 按实际云南州份定位。依据是国家登记表、当前州归属与本地化，具体证据保留在区域目录。本文不授权借叙事改动地图、州归属、人口或已经完成的开局法律配置。

##### 6.3 条件、分支与结局

每条重点线至少有两种成立的策略，每种都明确支持者、受损者、投入和机会成本。关键分歧至少被两个后续节点读取；临时事件选项可以较简单，但不能全线只增减同一分数。

所有长线有确立、有限妥协、受挫改道三种可执行收束，另允许主动撤回。确立后至少持续六个月满足核心执行条件，才进入巩固结果；突变或战时特殊线在卡片上明确例外。妥协与失败可以减少收益，但保留后续内容。

玩家提前满足法律或建设条件时，进入承认既有行动的执行/结果节点。国家灭亡、失去关键州、宗主变化、对手缺席、战争或革命改变立场时，重新判断当前权利与行动者，走替代分支或明确收束，不能恢复旧主权。

##### 6.4 成本、他国回应与 AI

每个主要选项在内容卡中逐项写明即时成本、持续时间、受益/受损对象及后续义务；资金发生真实扣款，跨国转移两端等额且共同检查收款方存续。不同规模国家独立校准成本，资金不足时提供缩小试办、延期或退出，避免一次事件造成无期限支出。

首卡以开启时财政能力折算费用。本轮已核对官方 `common/history/global/00_global.txt` 使用 `yearly_gross_income` 计算国家债务，故以开启时该年度政府收入×1/52作为一周费用基数，最低100的项目管理费在选项说明中明确。审计/补偿按卡片比例实际扣款；不猜测不存在的weekly_income字段，也不再使用早期暂定的GDP代理。收入快照保留，后续收入变化不能反复重置费用或领款。

首卡的半年、九个月是实际条件连续满足的最低观察期，计时结束不绕过共享主线90天投递间隔。十个顺次主线事件仅投递间隔便至少占27个月，不能承诺整条十事件线半年结束。受阻提示须依据真实条件不足或尚未履约，不能把只等待事件队列写成改革失败；36个月提供缩限或退出选择，不自动推翻已经达成的承诺。

常规修正默认 24 个月，危机修正默认 12 个月，专项结果可取 6—60 个月；同名修正不可通过重复触发无限叠加。长期制度效果依赖法律、承诺或实际条件，并有撤销条件。

多边安排至少两方独立决策。AI 依据本国关系、财政、政治立场、依赖和战争状态选择；每条线至少核验财政紧张、友好合作、敌对拒绝、战时四种 AI 情景，不预定唯一历史终点。

#### 七、推进、节奏与性能

国别可同时活跃的重点长线最多三条，默认显示的行动日志最多六条；其余以完成、待激活或概览呈现。非十国政体最多两条新日志同时活跃。

同一国家主动决策类主线事件默认至少间隔 90 天；独立常态风味事件默认每月最多一张，单一重复型风味至少 180 天间隔。既有跨危机季度冷却继续共用，等待投递不计答复超时。战争、政变等紧急事件可在清单中明确豁免，最多增加一张紧急决策，避免同日连弹。

推进主要依赖可见国情。卡在条件上持续十二个月时显示阻碍说明；三十六个月仍无进展时提供缩小、重谈或退出。期限不改变国家已经付出的真实成本。

AI 与全局检查按月或季度执行，仅遍历合格或活跃国家；避免每天遍历所有国家、州和人口。开局先投递必要入口，再分散展开支线。本轮通过脚本频次、遍历范围和活跃数量作静态性能审查，不启动游戏测量性能。

#### 八、技术组织、兼容与语言

增量输入统一放在 `data/content/v03/`，按国家、区域和主题拆分；既有 catalog 与生成文件保持各自归属。新增生成器只渲染自己的文件，不覆盖手工或旧生成器的输出。中文和英文随内容同批完成；游戏 `.yml` 写入 UTF-8 BOM，JSON 使用无 BOM UTF-8。

旧事件、日志、路线和变量 ID 保留；先冻结边疆 56 国现有 168 个事件的显式映射。新 ID 从预留区间分配并登记，增删国家不重排已有编号。可达性审计同时覆盖 `ywc_je_*` 和 `ywc_route_*`。

旧三章主线可作为已完成的前史或新线的入口。新版启用后每个国家每条旧线只有一个推进来源，旧结果接口由实际新结果映射，避免新旧双重收费、双重投递或把路线判定改成点击即成功。天命霸权读取新线真实宗藩结果与旧接口，保留一套顺逆答复与贡赋账目。

v0.3 以新档为完整内容验收基准。旧档保留加载与已有结果，启用时按已完成、进行中、未开始三类登记并决定接续位置；不回收已付成本、不清空既有法律与领土、不自动补领奖励。旧档兼容若有未证实部分，在验收记录逐项披露。

#### 九、开发顺序与完成标准
