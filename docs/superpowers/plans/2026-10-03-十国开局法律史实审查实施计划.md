# 十国开局法律史实审查实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 1836 年真实制度或永昌世界已确认的架空年表，校准十个主线国家的 Victoria 3 开局法律，并为每项选择留下可追溯依据。

**Architecture:** 先建立逐国证据表，再把证据映射到游戏已有法律；架空国家以项目年表为准，并单列历史类比。法律源数据分散于国别历史、开局配置与生成文件，实施时修改源文件并只更新对应目标国家。

**Tech Stack:** Victoria 3 法律类型与 Clausewitz 开局历史、JSON 开局配置、Python 标准库生成器、Markdown 史料表。

**Spec:** `docs/superpowers/specs/2026-10-03-开局叙事服饰宗谱与法律设计.md` 第 5 节。

## Global Constraints

- 范围限于 SHU、JHG、DMG、NMG、NQG、OIR、MGL、TIB、KOR、LAN。
- 真实历史国家以 1836 年制度为基准；架空政权以已确认的项目年表为先，并说明历史类比。
- 只使用 Victoria 3 已有法律，不为现代化或平衡而改写历史制度。
- 每个法律组只能启用一个互斥法律；检查其与宗教、政体、宗藩关系和日志条件的一致性。
- 保护现有未提交改动；只暂存本计划目标国家的法律数据和本次证据表。

## Review Focus

- 将史实与架空推演分开标注，不能把虚构政权称为真实历史政体。
- 对 1836 年制度证据标明来源、日期、具体支持的法律判断及不确定性。
- 游戏法律模型不能表达的制度要写出取舍理由，避免以现代国家分类直接套用。
- 国家法、税制、贸易、土地、宗教、奴役/劳役与公民权法律须分别审查，不复制一套模板给所有国家。
- `MGL` 是本地开局历史中使用的蒙古标签；核对其与场景注册中 `MNG` 标识的对应，避免改错国家。
