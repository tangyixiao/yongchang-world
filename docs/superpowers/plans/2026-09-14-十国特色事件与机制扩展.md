# 十国特色事件与机制扩展 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有十国日志与路线框架上增加十套可反复互动的特色状态、30 个承接事件和路线反馈，使每个国家形成可辨识的玩法差异。

**Architecture:** 每国使用一个 0—100 的 `ywc_flavor_<tag>_` 变量，由国家专属 scripted effect 负责初始化、增减和封顶；三个新的 journal entry 通过月度脉冲依次触发三个特色事件。现有路线只读取特色变量并获得轻量反馈，完成/失败/放弃清理协议保持不变。

**Tech Stack:** Victoria 3 1.13.11 Clausewitz/Jomini 脚本、YAML 本地化、JSON 内容清单、Python 标准库 `unittest`、PowerShell/静态脚本。

**Spec:** `docs/superpowers/specs/2026-09-14-十国特色事件与机制扩展设计.md`

## Global Constraints

- 保留现有日志 ID、路线 ID、事件 ID 和共享变量接口；已有未提交改动不回退、不格式化。
- 不修改 Victoria 3 本体、地图几何、州所有权、国家标签注册和既有 MGL/SHD 迁移。
- 不重新设计 `ywc_maritime_network_level` 等共享变量；若某特色需要海贸，只调用现有共享接口。
- 不新增永久领土奖励、全中国核心、免费工业化或绕过属邦/保护关系的独立效果。
- 中英文同时补齐；文案必须描述真实选择代价，不使用“保持可玩状态”作为特色理由。
- 变量范围固定为 0—100；`MNG` 内容的运行时国家标签继续使用 `MGL`，掸邦继续使用 `SHD`。
- 本轮写入完成前不执行测试、静态检查、隐藏启动或实机校验；这些命令只作为最后交付阶段步骤。

- Modify the four regional event files under `yongchang_world/events/`: add 30 events, three per country, using only the country’s flavor effects and existing shared interfaces.
- Modify the four regional event files again for the existing 20 routes: add high/low flavor feedback without changing route cleanup.
- Modify both `yongchang_world/localization/simp_chinese/ywc_content_l_simp_chinese.yml` and `yongchang_world/localization/english/ywc_content_l_english.yml`: all new JE, event, option, variable, and modifier text.
- Modify `data/content/content_catalog.json`: record flavor variable, flavor journal IDs, flavor event IDs, and flavor modifier IDs for each core country.
- Modify/add focused tests only after the content batch is written; no test command is run during the current write phase.

### Task 1: Shared Flavor State API

**Files:**
- Create: `yongchang_world/common/scripted_effects/ywc_flavor_effects.txt`
- Create: `yongchang_world/common/scripted_modifiers/ywc_flavor_modifiers.txt`
- Modify: `yongchang_world/common/history/countries/ywc_content_starts.txt`

**Interfaces:**
- Consumes: existing `COUNTRIES` country-history block and existing static modifier conventions.
- Produces: `ywc_flavor_<tag>_initialize`, `ywc_flavor_<tag>_bureaucracy`, `ywc_flavor_<tag>_local`, and `ywc_flavor_<tag>_feedback_high/low` for each of SHU, JHG, DMG, NQG, OIR, MGL, TIB, KOR, LAN, NMG.

- [x] **Step 1: Add the ten state names and catalog fields**

Add one `flavor` object to each country row in `data/content/content_catalog.json` with the exact fields `variable`, `journals`, `events`, `high_modifier`, and `low_modifier`. Use `MGL` for the Mongolian row’s runtime references.

- [x] **Step 2: Add bounded country-specific effects**

For every country, define an initialization effect and two direction effects. Each direction effect changes only its own variable and clamps it:

```text
ywc_flavor_shu_initialize = {
    set_variable = { name = ywc_flavor_shu_court_balance value = 50 }
    clamp_variable = { name = ywc_flavor_shu_court_balance min = 0 max = 100 }
}

ywc_flavor_shu_bureaucracy = {
    change_variable = { name = ywc_flavor_shu_court_balance add = 15 }
    clamp_variable = { name = ywc_flavor_shu_court_balance min = 0 max = 100 }
}

ywc_flavor_shu_local = {
    change_variable = { name = ywc_flavor_shu_court_balance add = -15 }
    clamp_variable = { name = ywc_flavor_shu_court_balance min = 0 max = 100 }
}
```

Use the country-specific effect names from the design table; do not introduce a parameterized scripted-effect syntax that is not already present in this Mod.

- [x] **Step 3: Add threshold modifiers**

Define one high and one low modifier per country. Use only modifier keys already used by this Mod (legitimacy, authority, bureaucracy, loan interest, military-goods cost, law enactment, port throughput, trade capacity, birth rate). High modifiers must be modest and low modifiers must be a real cost; neither may grant territory or rank.

- [x] **Step 4: Initialize each country exactly once**

At the beginning of each existing core-country block in `ywc_content_starts.txt`, call that country’s initialize effect before adding its existing journal entries. Add the three flavor journal entries in the same block. Do not alter the existing `ywc_reset_shared_variables` ordering.

- [x] **Step 5: Commit the shared state layer**

```powershell

git commit -m "feat: add ten-country flavor state layer"
```
