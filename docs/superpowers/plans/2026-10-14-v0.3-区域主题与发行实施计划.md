# v0.3 区域主题与发行实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成八场区域危机、63非十国政体、十二跨国主题，并完成全版本兼容逻辑、静态性能风险与离线验证。

**Architecture:** 共享国别管线和投递机制，区域危机按参与者分别决策，非十国按真实地理与制度定制，主题由事件事实连接不同国家。三时期内容以离线情景覆盖；现有实机发行门槛保留原状，本轮不扩展或运行观察矩阵。

**Tech Stack:** v0.3 catalog/generator、Clausewitz、Python unittest、现有脚本回归和静态校验工具。

**Spec:** 同日完整设计、区域危机与边疆内容目录、`docs/release/v0.3-acceptance.md`。

## Global Constraints

- 八危机≥96新事件/24JE；63政体各≥6事件/2JE；十二主题各≥8事件/1JE。
- 危机参与者自行选择，拒绝、缺席、战争、失州、宗主变化都有可执行结局。
- 旧危机与霸权单一账目、季度冷却、实际投递后才计超时，等额贡赋转移。
- 无DLC走基础分支；旧版发行门槛保持原逻辑；晚期内容用离线情景验证，不冒充真实观察。
- 任何证据不完整都保留pending，不能手填verified或用旧日志代替新运行。

## Review Focus

- 小国一次性成本超过财力：Task2断言有可支付检查和缩小/退出。
- 多场危机同时向同一国投递：Task1直接运行真实脚本跨危机测试。
- MHG、CHI或HSR等地理错位：Task2基于registry/history/州份的身份合同。
- 晚期没有实际观察证据但报告全世纪完成：Task4/5将1935点设为硬要求。
- 无DLC分支引用DLC对象：Task3/5分别静态和离线分支检查。
