# 大顺税册：预垫来源与债务防重放

## 目标与范围

财政税册线 E6 原卡要求有真实海商/港口基础；无港口时可提出地方预缴，不能无中生有。当前源码的旧选项可在已还款后再次领本金，也可在已有未还债时重放拒绝选项、绕过地方结算门槛；旧弹窗重放是离线模型反例，不等于已证实游戏自然重复弹窗。

- 为预垫选项读取真实拥有、在岗且无短缺的港口或农业建筑；没有任何合格来源时仍可无费用拒绝。无港口但有合格农业时文案为地方预缴，不声称凭空发现特定商人或人物。
- 接受与拒绝为一次性的互斥记录，UI 条件与 effect-time 均重检；本金偿还后重放旧选项不能再次收款，也不能覆写后续队列。若事件重新打开且已有记录，提供只在原阶段可恢复队列的继续选项。
- 对已有矛盾存档，未还本金优先于旧的 `repaid/refused` 标记；不得通过地方审计或地方结案，直至实际偿还。既有本金、已还款及退出后月度追偿不被清除。
- 用真实源码驱动的事件队列和原月度子回调测试来源、首笔、偿还、旧选项、冲突标记、失源与旁路；先记录失败，再实现。双语文本和生成文件同步。
- 冻结精确源码，执行大顺、跨国与生成/静态检查、独立复核；只提交本批文件，保留不启动游戏、Steam 或 UI 的边界。

军费预付款的现金/违约门槛、十二个月承诺、地方承担者与后续军制线读取是独立剩余工作，本批不宣称完成。

## 实施与兼容边界

新预垫必须有实际拥有、就业至少一半且没有投入品短缺的港口或农业建筑。预垫会增加国库并留下本金债务，但现有系统没有从具体商人或人口账户扣款；不能据此声称做了双边转账。新债以变量计时满十二个历月后，在后续月检中偿还；本金不足则保留债务与逾期影响。旧债没有新计时器时，继续按原有十二次月检与实际余额规则处理。

选项执行时重新检查互斥决定、阶段与队列；有未还债时，旧版可能共存的已还/拒绝标记不允许绕过地方核账和结算。已打开但尚未选择的预垫事件，在试点失地后恢复到自身；正常二核计时和三年兜底不会跳过它或一个已经启动的前置环节。无首核且长期卡在官署的三年兜底仍可进入有限试点退出。实际已排入的旧队列优先保留。预垫尚未偿还或执行能力不足时可明确等待并重试，不改变还款期限或覆盖另一阶段队列；同一核账事件的重复排队可被本次成功核账消费。

旧版缩限选项没有独立记录，而更早选项也可能写入旧额标记。一种历史调度曾先清除 1006 队列再发送事件；跨版本存档若恰好停在发送和 immediate 之间，国家变量不足以区分“旧缩限已选择”和“1005 刚显示尚未选择”。当前调度保留队列直到 immediate 确认，但不能证明所有历史存档的该窗口都能无歧义迁移。离线回放仅证明模型中的行为，不证明游戏会自然生成这些重复弹窗或跨存档时序。

本批未启动游戏、Steam 或图形界面；离线模型、生成和静态检查不能代替引擎、存档、AI 或玩家体验验证。军费支出及后续军制线关联仍需单独完成。
