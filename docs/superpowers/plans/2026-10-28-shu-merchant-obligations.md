# 大顺税册：预垫来源与债务防重放

## 目标与范围

财政税册线 E6 原卡要求有真实海商/港口基础；无港口时可提出地方预缴，不能无中生有。当前源码的旧选项可在已还款后再次领本金，也可在已有未还债时重放拒绝选项、绕过地方结算门槛；旧弹窗重放是离线模型反例，不等于已证实游戏自然重复弹窗。

- 为预垫选项读取真实拥有、在岗且无短缺的港口或农业建筑；没有任何合格来源时仍可无费用拒绝。无港口但有合格农业时文案为地方预缴，不声称凭空发现特定商人或人物。
- 接受与拒绝为一次性的互斥记录，UI 条件与 effect-time 均重检；本金偿还后重放旧选项不能再次收款，也不能覆写后续队列。若事件重新打开且已有记录，提供只在原阶段可恢复队列的继续选项。
- 对已有矛盾存档，未还本金优先于旧的 `repaid/refused` 标记；不得通过地方审计或地方结案，直至实际偿还。既有本金、已还款及退出后月度追偿不被清除。
- 用真实源码驱动的事件队列和原月度子回调测试来源、首笔、偿还、旧选项、冲突标记、失源与旁路；先记录失败，再实现。双语文本和生成文件同步。
- 冻结精确源码，执行大顺、跨国与生成/静态检查、独立复核；只提交本批文件，保留不启动游戏、Steam 或 UI 的边界。

军费预付款的现金/违约门槛、十二个月承诺、地方承担者与后续军制线读取是独立剩余工作，本批不宣称完成。
