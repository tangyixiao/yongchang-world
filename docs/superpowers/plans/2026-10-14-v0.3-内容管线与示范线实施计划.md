# v0.3 内容管线与示范线实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 保护既有内容接口，建立独立内容管线，并完成 SHU、DMG、KOR 各一条有真实治理后果的示范线。

**Architecture:** 新 JSON 清单直接保存明确的文本与游戏脚本片段，生成国家分文件的事件、日志和双语文本；共享生命周期与兼容效果手工维护。先修补旧 ID 与路线审计，再以三条完整线证明管线能表达不同玩法。

**Tech Stack:** Python 标准库、unittest、JSON、Clausewitz/Jomini、UTF-8 BOM YAML、现有 `tests/clausewitz_harness.py`。

**Spec:** 同日完整设计第五—八节、十国目录的三条详细示范卡。

**2026-10-16执行结果：** 本子计划M0/M1已通过实现与离线验收，实现提交 `229c73e`。三国30事件/6日志；主代理649全仓测试、126项v0.3回归、总检查和新旧生成check通过，独立复审无本批未解决P1/P2。实际prototype行为测试拆分到三份 `tests/test_v03_{shu,dmg,kor}_content.py`，证据索引为 `data/content/v03/prototype_review.json`；不重复建立镜像聚合测试。各步骤的历史执行与修复记录见总计划SDD ledger，最终证据见 `docs/release/v0.3-acceptance.md`。完整v0.3目标仍未完成，下一项为十国子计划Task1。

## Global Constraints

- 总计划约束全部适用。新增示范30独立事件、6日志，计入十国720/180。
- 旧事件、路线、变量与边疆映射不重排；新生成器不写旧生成器输出。
- 不执行关键词猜成本、随机拼剧情、正负分模板；每个效果来自明确卡片。
- 未支持的引擎命令不能在离线解释器静默通过。

## Review Focus

- 同一路线被新旧两套脉冲推进：Task 3 的重复初始化/重复投递测试。
- 国家排序新增导致旧 ID 变化：Task 1 的新增 tag 变异测试。
- 跨国不存在却仍扣款：Task 3 的收款方灭亡/转移守恒测试。
- JSON 输出写出拥有目录：Task 2 的路径穿越与文件归属测试。
- 原先已有法律被当作待改革：Task 4 的提前完成与改革撤回测试。

### Task 2：新内容输入、确定性生成与校验

**Files:** Create `data/content/v03/manifest.json`, `data/content/v03/id_registry.json`, `data/content/v03/countries/{shu,dmg,kor}.json`, `tools/build_v03_content.py`, `tools/ywc_v03_check.py`, `tests/test_v03_catalog.py`, `tests/test_v03_generator.py`。

**Interfaces:** `load_catalogs(root: Path) -> dict[str, dict]`；`validate_catalogs(catalogs: dict[str, dict]) -> list[str]`；`render_all(root: Path) -> dict[Path, str]`。生成器 CLI `--root . [--check]`；校验器 CLI `--root . [--require-complete] [--json]`，出错返回1。

Manifest 字段固定：`schema_version=1`、`release="0.3"`、`catalogs`（显式相对路径列表）、`targets`（四层事件/日志下限）、`owned_outputs`。各内容清单含 `key`, `layer`, `runtime_tags`, `arcs`；每 arc 有 `slug`, `era`, `participants`, `depends_on`, `journals`, `events`, `outcomes`, `legacy_links`。每 event 有 `id`, `title`, `desc`, `trigger`, `immediate`, `options`, `purpose`, `reads`, `writes`；本地化字段为 `{zh,en}`，option 含 `key`, `label`, `effect`, `ai_chance`, `cost_note`, `consequence_note`。每 journal 有 `id`, `title`, `desc`, `script`, `goal`, `exit_conditions`。脚本为明确 Clausewitz 块，不创建另一个表达式语言。

ID 预留：各国原 namespace 的 `.1000`—`.1999`，MGL 沿用 `ywc_mng`；危机 `ywc_crisis.1000`—`.1799`；跨国主题 `ywc_society.1000`—`.1599`；63非十国 `ywc_regional.1000`—`.7299`。登记表显式分配国家/线对应区间，不能由输入排序推算。

产出：`events/ywc_v03_<key>_events.txt`、`common/journal_entries/ywc_v03_<key>_journal.txt`、两语言 `ywc_v03_<key>_l_<language>.yml`。输出根始终为 `yongchang_world`。
