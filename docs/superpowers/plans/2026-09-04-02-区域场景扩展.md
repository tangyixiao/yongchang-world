# 区域场景扩展 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在四国垂直切片稳定后，按已批准年表补齐东北、内亚、西藏西南、菲律宾、南洋、太平洋和下加利福尼亚的1836场景。

**Architecture:** 先用1.13.11本体的`state_regions`和`00_states.txt`建立Province账本，再将所有权、人口、建筑和外交分别写入对应历史文件。底层地图几何不变；只有`STATE_SAKHALIN`、`STATE_LUZON`、`STATE_BAJA_CALIFORNIA`等边界重叠地区使用明确的Province子集。

**Tech Stack:** Victoria 3 1.13.11地图/历史数据库、Clausewitz脚本、Python标准库账本校验器、PowerShell日志工具、Git。

**Spec:** `docs/superpowers/specs/2026-09-04-01-1644至1836历史年表.md`、`docs/superpowers/specs/2026-09-04-02-1836开局剧本.md`、`docs/superpowers/specs/2026-09-04-03-Mod技术框架.md`。

## Global Constraints

- 只使用`E:\SteamLibrary\steamapps\common\Victoria 3`的1.13.11数据，不改地图几何。
- 每个Province在1836只能有一个所有者；所有新增国家必须先通过TAG注册表检查。
- 大顺只直接控制规格中列出的汉地、辽东、吉林中南部、河西、西宁周边和云南核心。
- `NQG`保持三万至六万人；`NMG`保持墨西哥争议自治属邦；北澳只有一处小型商站。
- 东明不拥有马尼拉，靖海不拥有厦门/金门，兰芳与`WBK`不自动成为大顺殖民地。
- 本计划新增的地方国家只有基础开局资料和一条核心日志；完整路线留给下一份内容计划。
