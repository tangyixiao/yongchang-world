# AI平衡DLC与发行验收 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在内容和区域场景完成后，控制主要国家的早期行为，接入三组DLC能力而不让无DLC开局报错，并通过1836—1900多种子观察局形成v0.1发行候选版。

**Architecture:** AI只通过战略、外交偏好和有限国家修正控制行为；不使用永久免费军力或领土效果。DLC能力放在独立compatibility文件中，以`has_dlc_feature`为门禁；基础路径永远先执行。观察局工具负责启动记录、关键年份截图/日志摘要和异常分类，最终由人工确认玩法质量。

**Tech Stack:** Victoria 3 1.13.11 AI strategy、scripted modifiers、DLC feature triggers、PowerShell、Python标准库、Git。

**Spec:** `docs/superpowers/specs/2026-09-04-02-1836开局剧本.md`、`docs/superpowers/specs/2026-09-04-03-Mod技术框架.md`。

## Global Constraints

- 目标版本固定为`1.13.11 (Matcha)`；不提前适配1.14或Century of Strife。
- 不改变国家存在条件，不以AI修正替代错误的州、人口和外交数据。
- 防止大顺立即吞藩、俄罗斯过早吞并整个内亚、西班牙秒杀东明、荷兰无阻力吞并兰芳、英国席卷南洋、靖海殖民非洲、墨西哥开局吞并新明。
- DLC能力标识固定使用本体已核验的`ep1_content`、`mp1_content`、`ep2_content`。
- 五套测试配置为无DLC、仅Sphere of Influence、仅Charters of Commerce、仅The Great Wave、三者全开。
- 观察局使用至少三个随机种子，并保存1846、1866、1900三个检查点的统计。
