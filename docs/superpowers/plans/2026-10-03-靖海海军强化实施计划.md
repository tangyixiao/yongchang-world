# 靖海国海军强化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让靖海开局拥有 8 艘护卫舰和相称的海军行政与船坞基础，成为模组东亚自定义政权中最强的海军国家。

**Architecture:** 只调整现有开局舰队和台湾的海军支持建筑，复用已存在的郑氏海贸、护航与海军援顺日志路线；保留帆船科技、既有陆军和藩属身份。

**Tech Stack:** Victoria 3 Clausewitz 国家开局、建筑与军事编制历史文件。

**Spec:** `docs/superpowers/specs/2026-10-03-开局叙事服饰宗谱与法律设计.md` 第 6 节。

## Global Constraints

- 靖海开局为 8 艘护卫舰、3 级海军行政（`reserves = 2`）和 2 级船坞。
- 保留帆船科技，不给予蒸汽舰或超出开局科技层级的技术。
- 不改变靖海陆军数量、人口、税制、领土、宗藩关系和既有海军将领。
- 沿用现有海贸网络和海军援顺日志/事件，不增造重复海军机制。
- 保护未提交的其他开局改动；只暂存本计划列出的目标块。

## Review Focus

- 初始舰队舰种须仍为护卫舰，舰数准确为 8。
- 海军行政等级、生产方式及 reserves 字段不能误改同区域其他国家。
- 船坞升级只落在靖海控制的台湾州。
- Shun 当前 6 艘护卫舰、14 个靖海陆军营和科技层级不变。
- 海军援顺/护航日志仍使用原 ID、变量和结果协议。
