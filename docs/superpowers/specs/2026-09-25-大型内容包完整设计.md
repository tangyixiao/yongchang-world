# 《永昌世界》大型内容包完整设计

日期：2026-09-25
状态：内容与机制设计定稿；不包含游戏脚本或实施任务拆分。

本规格由[设计框架](2026-09-25-大型内容包设计框架.md)、[十国事件卡](2026-09-25-大型内容包十国事件卡.md)和[跨国危机事件卡](2026-09-25-大型内容包跨国危机事件卡.md)组成。三个文件合起来定义全部 180 个新事件的用途、顺序、参与者、抉择、代价、反馈和结局。原有 30 个特色事件另作各章前奏，未计入 180 个。

## 1. 可玩目标与边界

十国玩家从 1836 开始能经历三段有区别的政治社会变迁；每段都有国内反对力量、实际资源约束和对外反应。五场危机使不同国家的战役相互影响。玩家结束第三章后，所选制度、条约和社会关系继续产生长期后果。内容覆盖胜利、妥协和挫败，任一种结局都允许继续正常游玩。

1836 前沿用既定正史。1836 后不规定“大顺最终统一”“靖海必独立”或真实世界的列强战争、革命、二战结果。保留现有地图、州所有权、国家标签、主日志、20 条路线和共享变量接口；不直接赠送全中国核心、领土、工厂或属邦独立。小国规模和宗主关系继续约束东明、北清、兰芳、新明与靖海。

## 3. 章节生命期与事件节奏

1. **激活**：国家存在且为本国玩家或 AI，当前章前序条件满足，且尚未结算；第一章从 1836 开始可见。第二章在第一章结算、经历足够的社会变化后开放；第三章要求第二章结算及外交、经济或法律领域发生可观察的转折。战争、革命或区域危机可提前造成转折，不以固定年份锁死。
2. **前奏**：既有特色事件保持原 ID 和文案意图，作为本章的第零节；不再在第一次弹出后立刻把整章判定为已完成。原有日志 ID 与 `resolved`、`failed` 结果标记保持对外可读，但写入时点移至该章结算。
3. **五个新事件**：事件卡按编号顺序推进。前四个是议题、投入、反对与外部回应，末一个是结算抉择。每个事件只可发生一次；结算前事件间至少经过一个季度，并由具体现实条件或上一步决策驱动，避免同月连弹五次。
4. **结算**：每章至少有“制度确立”“脆弱妥协”“受挫改道”三种结果。制度确立要求相关法律、财政、市场、建筑、条约或关系的实际条件成立，不能只数点击次数；妥协保留有限收益和后续问题；受挫产生有时限的反弹并进入下一章。玩家可以在末事件选择保守收束，避免被动卡死。
5. **延续**：下一章读取上一章结局、原有十个特色状态变量、现有共享变量和既有长期路线。第三章结束后只保留有上限、能因局势改变而撤销的余波修正或外交安排，不无期限循环弹出同一事件。

设计上的每章五个事件均应进入正常玩家战役；若国家已灭亡、关键地区不再由它持有、相关对手消失或宗主关系变化，改走卡片注明的替代语境。此时保留同一事件 ID 的可达性，不凭空恢复国家或疆土。

## 4. 共同机制契约

| 机制 | 读取 | 改变及上限 | 玩家看到的后果 |
|---|---|---|---|
| 国家特色状态 | 现有十个 `ywc_flavor_<tag>_*` 0—100 变量 | 仍通过既有国家效果增减；不把“高”简单解释为道德上更好 | 本国合作或失衡、不同集团得失，影响章末和既有路线 |
| 正统性、海贸、自治 | 现有 `ywc_heritage_legitimacy`、`ywc_maritime_network_level`、`ywc_autonomy_pressure` | 只经现有共享效果及其边界处理；不重建第二套同义变量 | 主日志和跨国危机读取该国真实水平 |
| 政治联盟 | 既有利益集团、领袖、法律与政治运动 | 事件改变支持、反对和临时动员，不凭空通过法律；地方代表与身份保障可形成长期争议 | 法案能否通过、反对运动强弱、第三章政治道路 |
| 财政与生产 | 预算、债务、港口、市场接入、建筑规模和就业 | 有成本的短期修正、投资权、条约、建筑效率；无免费工业化或不存在的资源发现 | 玩家能从市场、账本和州面板验证效果 |
| 外交与主权 | 关系、主体身份、条约、外交利益和战争状态 | 协议可接受、拒绝、违约与再谈判；拒绝不自动产生征服权 | 双方都有选择，条约权利义务可读 |
| 文化与知识 | 学校、识字、人物、传教、出版与商人网络 | 在相关建筑与资金存在时改善知识传播、政治认同或声望 | 小国也有非军事发展路径 |

数值平衡约束：常规单事件修正先按 2—5 年时限设计；紧急危机按 6—24 个月设计；不能永久堆叠。财政成本按国家规模分级，小国不得因一次事件承担超过其可承受的永久支出。较强收益需至少一种实际投入和一种集团或外交代价；成功结局不可覆盖失败成本。具体引擎数值与可用效果 ID 在实施时对照游戏数据校准；这不改变本规格确定的选项、代价类型和结局门槛。

### 4.2 章节状态与可读信息

每章持有“未开始、前奏、五节中的一节、成功、妥协、受挫”之一；成功、妥协、受挫互斥。事件卡的一、二、三、四号依次记录议题、投入、反对、外部或社会回应；五号读取实际条件结算。政治集团或外国的拒绝不清除玩家已付成本。若玩家先行完成要求，结算可承认此前行动；若玩家暂时失败，第五节必须提供低收益但可执行的退出路径，不能让日志永久悬挂。

正常速度下同一章计划跨越数年；最低一季度间隔适用于相邻新事件，不限制已经发生的前奏。起始年份不决定结果；章节所依赖的法律、贸易或外交变动若长期未发生，应以国内请愿、财政审查或邻国照会提供该章自己的进入议题。危机可插入章节，但同一国家每季度最多收到一张主动决策的危机卡；其它回应由日志或通知显示，避免开局与危机叠加弹窗。

中英文各需 180 个标题、180 个正文、至少 360 个主要选项说明、35 条日志标题与阶段说明，另为三类章节结局、五类危机结果和条件不可用原因提供文本。事件卡名称是中文内容锚点，不代表最终本地化键名。文本须标明架空世界线的前提，并将真实历史参照、世界线推演和游戏效果分开校对。

## 5. 五场危机的共享判定

每场危机有一个主日志与一个持有人。主日志负责阶段推进和一次性结算；其他参与国通过各自的事件选择、外交行动或已有日志获取目标和反馈。危机不能只由持有人替所有国家做决定。参与国的沉默、失去资格和 AI 超时都要转化为明确的“拒绝”“谨慎观望”或“无人代表”结果。

主日志可在相关争议实际存在时出现，且与同一危机的其他实例互斥。危机六节分别为：提出要求、主对手回应、邻国或本地集团回应、筹资与动员、升级或让步、协定/破裂结算。跨国事件每个 ID 在一场危机中只登记一次；对不同国家使用条件选项或子通知，防止参与者数乘出意外事件量。

危机效果以实际国家和市场状态为准。宗主消失、受邀国灭亡、条约已被其他战争改变时，阶段立即重算；无法继续的谈判进入合法的缩小协议或无协议结局。战争期间不授予免费的和平条约、州所有权或无条件停战。

## 6. AI、玩家提示与可达性

- AI 权重先看国力、市场、法律、主体地位、邻国关系和既有路线，再看历史倾向。不能为重现现实历史给某国不可解释的永久增益。
- 每章两个方向均有 AI 合理选择窗口；低财政国家偏向节制、受威胁小国偏向防务、贸易受阻时海洋路线权重下降。AI 不应选择自己已无法支付或条件已消失的选项。
- 日志显示当前阶段、下一步所需条件、主要受益与受损集团及可能卷入的国家。隐藏数值转译为清楚的政治经济说明；事件选择应显示成本与持续时间。
- 三章在十国从正常 1836 新档均可进入；全程不要求玩家对别国选取某条路线才看见自己第三章。交叉危机是加深或改写章节的途径，不是十国长线的唯一开关。
- 新内容以新档为设计基准。由于原有特色日志会从“一次事件即结算”改为五节战役，旧存档需另行设计迁移；不能将兼容性当作已验证事实。

## 7. 设计完成与后续验收口径

本规格锁定了 30 个章节、150 张国家事件卡、5 场危机、30 张危机事件卡、三类章节结局和参与国应答关系。实施时的内容清单需逐项登记 ID、来源日志、参与者、触发、选项、影响的机制、结局和中英文键。事件缺少任何一项核心作用时，不计入 180 个目标。

设计审查需检验：十国都能独立进入三章；五场危机均有至少两个可行动参与者；事件编号唯一；没有因固定日期、已灭亡对手或 DLC 缺失而永远无法进入的必需事件；失败和拒绝均有可玩收束；旧日志和路线接口被准确引用。脚本、静态、本地化、实际 UI 与长战局运行另属于实施阶段的验证，不以本设计文档代替。
