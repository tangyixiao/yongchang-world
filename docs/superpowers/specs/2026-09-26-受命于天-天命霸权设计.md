# 《永昌世界》v1.0「受命于天，既寿永昌」先行层：天命霸权设计

日期：2026-09-26
阶段：版本设计与实施依据；承接大型内容包三章战役与五场危机的既有接口。

## 1. 版本定位

三章战役结束后，天下秩序进入"天命霸权"阶段：大顺（或完成第三章并确立其对外秩序的宗主）颁行朝贡新制，各国必须在新秩序面前表态——**顺我者昌**（入贡者得互市之利与保护之实），**逆我者亡**（拒诏者承受孤立、倾覆之危与霸权问责）。"顺"字双关大顺国号；版本主题是宗藩秩序从"名分再议"走向"制度化霸权"。

与既有约束的一致性：

- **昌不是白给**：入贡者付出真实贡赋（国库转移）、自主压力与朝贡义务，换取有时限的互市、正统性与保护修正。
- **亡不是免费吞并**：拒诏者承受有期限的孤立与不稳修正、关系崩坏与霸权问责；实际征服只能走游戏内既有外交博弈与战争系统，事件永不直接转州、不直接灭亡国家、不直接释放属邦。
- **霸权可以失败**：权威不足、顺逆失衡或宗主自身不稳时，新制受挫甚至崩解，霸权承受反弹修正；三国结局之外同样允许继续游玩。

## 2. 触发与资格

`ywc_je_hegemony_order` 挂到大顺，条件（二者其一 + 共同条件）：

1. 大顺第三章以"制度确立"结算（`ywc_campaign_shu_c3_outcome = 1`）；
2. 危机一"天下名分与宗藩再议"以多方平等协议结算（`ywc_campaign_crisis1_outcome = 1`）；
3. 共同条件：大顺存在、`ywc_heritage_legitimacy >= 60`、九个参与国中至少四个存在，且同一霸权实例尚未启动（互斥标记）。

参与国：靖海 JHG、朝鲜 KOR、兰芳 LAN、北清 NQG、东明 DMG、喀尔喀 MGL、西藏 TIB、卫拉特 OIR、新明 NMG。新明的应答受墨西哥属邦身份约束（自治压力机制），跨洋使团是独立叙事而非宗主变化。

## 3. 霸权线（`ywc_hegemony.1`–`.6`，持有人大顺）

| 阶段 | 事件 | 内容 |
|---|---|---|
| 颁诏 | `.1` 颁行新制 | 宽仁之诏（权威起点低、正统代价低）或威严之诏（权威起点高、各国抗拒概率上升） |
| 应答期 | （推进效果逐季投递 `.200`） | 依固定顺序每季度向一个未应答的存续参与国发出诏使；答复记录在该国 |
| 抚震 | `.2` 四方震动 | 首批奏报入京：广施恩信或张威慑止，定后续基调 |
| 酬顺 | `.3` 酬顺之政 | 对顺服国施礼：互市特许、正统抬升、宗主权威上升；顺服国各自收到 `.201` 的本国视角事件 |
| 问逆 | `.4` 问罪逆藩 | 对拒诏国施压：孤立与倾覆之危修正、关系崩坏；拒诏国收到 `.202` 的本国视角事件，可转顺或硬抗 |
| 朝会 | `.5` 朝会天宪 | 对观望国最后施压与招抚；霸权选择收权或共治 |
| 结算 | `.6` 天命所归 | 依权威、顺逆比例与正统性结算：天命确立 / 新制受挫 / 霸权崩解，三种互斥结局均有余波修正并结束日志 |

## 4. 参与国线（每国 `.200`–`.202`，共 27 个）

- `.200` 诏使至国：三国抉择——入贡顺服（贡赋 + 自主压力，得保护与互市许诺）/ 暂观其变（低成本，两头下注）/ 拒诏明志（关系受损、暴露于问责）。每国文案按其第三章结局与地理处境单独撰写，不共用换名文本。
- `.201` 顺者之昌：仅顺服国收到；加贡换厚赏或谨守本分，均有时限。
- `.202` 逆者之亡：仅拒诏国收到；硬抗到底（承压加深、霸权权威受考验）或转而入贡（付出体面代价换取出路）。

应答记录：`ywc_tribute_answer`（1 入贡 / 2 观望 / 3 拒诏 / 0 无人代表）记在参与国；大顺维护 `ywc_hegemony_authority`（0–100）。国家灭亡时视为"无人代表"，不阻断霸权线。

## 5. 机制契约

| 机制 | 读取 | 改变与上限 |
|---|---|---|
| 权威 | `ywc_hegemony_authority`（大顺 0–100） | 应答、酬顺、问逆、朝会调整；结算读门槛 |
| 共享变量 | 正统性、海贸、自主压力 | 只经既有共享效果增减，界限不变 |
| 贡赋 | `add_treasury` 双向转移 | 入贡为真实国库转移，数额按国家规模分级，零和 |
| 修正 | 新增六个限时修正 | 朝贡互市 24 月、逆藩之罚 24 月、天命确立/受挫/崩解余波 60–120 月、霸权威仪 24 月 |
| 征服 | 无 | 拒诏不产生征服权；倾覆只经由既有外交博弈与战争系统 |
