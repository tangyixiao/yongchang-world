# 《永昌世界》世界观总纲

版本：设计草案 v0.1  
基准日期：2026-09-04  
目标：为 Victoria 3 的 1836 开局重构提供统一的历史设定、内容边界和冲突裁决规则。

## 一、项目定位

《永昌世界》（The Yongchang World）不是“把大清换成大顺”的换皮剧本，而是推演：

> 如果吴三桂在1644年接受大顺招降、清军未能入关，那么没有清帝国的东亚、内亚、南洋与西太平洋，到1836年会形成怎样的国际体系？

大顺是最大的国家，但不是唯一主角。项目保留原对话已经确定的北京李氏、台湾郑氏、吕宋朱氏、库页爱新觉罗、美洲朱氏、卫拉特、喀尔喀、西藏、兰芳及太平洋诸国。

## 二、设定继承规则

本草案以原对话为主稿，采用以下优先级：

1. 用户后来明确确认的设定覆盖早期设想。
2. 同时成立但互相矛盾的内容，保留辨识度更高的一项，并补足因果链。
3. 大胆设定不因概率较低而删除，但必须写明使其成立的额外分歧点。
4. 1836以前采用统一正史；1836以后不预定1900或1950结局。

## 三、1836标准世界线

- `SHU 大顺`控制汉地主要省份、海南、辽宁和吉林中南部。
- `JHG 靖海国`由郑氏统治台湾、澎湖，是大顺的高度自治藩国。
- `DMG 东明`由鲁监国系旁支及南明军民在吕宋北部建立，已演化为华菲混合国家。
- `NQG 北清`是爱新觉罗朝廷历经辽东、吉林、黑水退却后在库页岛形成的小国。
- `NMG 新明`由永历系流亡宫廷与美洲明裔社群在墨西哥独立战争中形成，1836年仍是墨西哥的争议自治属邦。
- `MON 喀尔喀汗国`独立，在俄罗斯和大顺之间摇摆。
- `OIR 卫拉特汗国`是准噶尔继承国家，控制伊犁、塔城及准噶尔盆地中西部。
- 塔里木盆地由哈密、吐鲁番、库车—阿克苏、喀什、叶尔羌、和田等绿洲政权分治。
- `TIB 西藏`控制卫藏核心；青海和康区另有和硕特、德格、嘉绒等政治体。
- `KOR 朝鲜`完全独立，“小中华”思想强于现实，但仍与大顺维持贸易和外交。
- `LAN 兰芳`、西婆罗洲公司、明香及其他华人政治组织在南洋活动，但不是大顺殖民地。
- 靖海通过商馆、投资、护航和条约连接帕劳、雅浦、波纳佩、马绍尔、望加锡和北澳，不直接统治半个太平洋。

## 四、核心政治主题

### 大顺

大顺是海贸较发达、东北开发较早的传统农业帝国，不是提前完成工业革命的超级中国。它的结构性矛盾是：

- 缙绅土地秩序与中央财政；
- 世袭武勋与文官官僚；
- 海商资本与传统政治资格；
- 东北移民与边疆部族权利；
- 西北影响力与国家行政能力；
- 对外贸易收益与鸦片、关税、司法权冲突。

### 靖海

郑氏放弃恢复朱明，接受大顺正朔，却保留舰队、财政、商议会和海外网络。其核心矛盾是忠顺、自治与海洋领导权。

### 明清遗产国家

东明、新明、明香、兰芳和北清不是缩小版旧王朝：

- 东明是朱氏礼仪王权、明裔军户、华商和吕宋本地贵族的联合体。
- 新明是天主教化、华墨混合的美洲边疆国家。
- 明香奉明文化但由商人和军政家族掌权。
- 兰芳保留明遗民文化，却采取公司共和制度。
- 北清是满洲皇室领导的北太平洋多族小国。

## 五、因果距离

### 第一圈：全面重写

中国、满洲、蒙古、准噶尔、塔里木、西藏、朝鲜、台湾和吕宋北部。

### 第二圈：显著改写

俄罗斯亚洲边疆、越南、缅甸、暹罗、婆罗洲、菲律宾、密克罗尼西亚和北澳。

### 第三圈：有限改写

英国、荷兰、西班牙、印度、日本、夏威夷和墨西哥保留主体历史，只修改与东亚贸易、殖民和外交直接相关的部分。

欧洲革命、美国独立、拿破仑战争和维也纳体系不因1644年的中国政权更替自动消失。

## 六、可信度标记

后续文档中的设定分为三类：

- **基础分歧**：大顺守住北京、逐步官僚化。
- **因果延伸**：东北较早移民、准噶尔未遭清军毁灭、南洋华人网络增强。
- **游戏性分歧**：东明长期存续、北清迁居库页岛、新明在下加利福尼亚自治。

游戏性分歧仍是1836正史，但必须保留其额外条件、弱国规模和生存压力。

## 七、已解决的原对话冲突

| 冲突 | 最终裁决 |
|---|---|
| 台湾有时属于大顺直辖 | 台湾属于靖海，大顺拥有宗主权和共同市场 |
| 郑氏有时仍代表南明 | 郑氏归顺大顺；朱氏遗民另建东明、明香、新明 |
| 清廷有时被写成完全灭亡 | 爱新觉罗朝廷残存并迁往库页岛，形成北清 |
| 东明与西属菲律宾边界不清 | 东明控制吕宋北部，西班牙控制马尼拉、米沙鄢和主要港口 |
| 新明抵达美洲便独立 | 流亡社群先存在约150年，墨西哥独立战争才提供自治机会 |
| 靖海直接殖民北澳、密克罗尼西亚 | 改为商站、投资、护航和保护关系，当地国家继续存在 |
| 海贸直接导向工业革命 | 只带来商业、财政、造船和知识传播优势 |
| 大顺自动继承清朝内亚疆域 | 蒙古、新疆、西藏和青海保持独立或分裂 |
| 1900年后复制现实战争和革命 | 从1836起交给游戏系统，不列为正史 |

## 八、v0.1边界

v0.1聚焦1836开局及此后的游戏系统，不制作固定的1931、1937、1949或1950剧情。科技树和商品体系沿用原版；只调整初始科技、修正、公司、日志和事件。

完整内容国为：大顺、靖海、东明、北清、卫拉特、喀尔喀、西藏、朝鲜、兰芳、新明。其余国家先达到正确开局和一条核心日志。
