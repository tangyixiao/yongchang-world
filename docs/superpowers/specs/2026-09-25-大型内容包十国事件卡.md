## 三十章结算门槛与余波

下表中“确立”均要求对应国家已具备所列实际条件，不能只凭前四节的选择获得。条件未完全满足但保有一部分资源时进入“妥协”；关键资源或政治合作失去时进入“受挫”。三种状态都开放下一章，后两者把下述问题带入后续阶段。

| 国家与章末 ID | 制度确立的门槛与收益 | 妥协、受挫的可玩余波 |
|---|---|---|
| SHU `.104` | 行政与税收足以执行朝廷预算协议；整合阻力下降 | 只确立地方分税；或派系阻滞使第二章海关预算更紧 |
| SHU `.109` | 港口、海关收入与政治支持同时存在；海贸收益可核对 | 仅区域海关；或走私反弹，第三章宗藩报价更昂贵 |
| SHU `.114` | 外交对象同意且边防可支付；形成有期限的平等或层级协议 | 仅双边礼仪安排；或承认多国边疆并加强国内防务讨论 |
| JHG `.104` | 王府、商人与国库能履行护航承诺；财政信用改善 | 保留部分航路；或失信使第二章保险和舰队成本更高 |
| JHG `.109` | 舰队、港口和伙伴回应足以运行航路；南洋商路稳定 | 只保主港护航；或过度承诺损债务与第三章成员信任 |
