# 《永昌世界》大型内容包：跨国危机事件卡

本文件是[完整设计](2026-09-25-大型内容包完整设计.md)的跨国部分。五场危机各有一条新日志、六个新事件，共 30 个。事件每场最多启动一次，按编号推进；其中参与国的回应必须由该国作出，持有人只记录回应。事件卡中“默认”只用于 AI 超时、国家灭亡或已无资格作答。危机可以独立结束为协议、有限妥协或破裂；破裂增加外交风险，不直接宣战、转让州或强制改变属邦关系。

## 危机一：天下名分与宗藩再议

日志：`ywc_je_crisis_suzerainty`；事件 `ywc_crisis.1`—`.6`。主角是大顺 SHU、靖海 JHG 与独立朝鲜 KOR；东明 DMG 在相关海贸争议存在时加入。大顺持有日志；大顺不在时改由靖海发起双边贸易与礼仪谈判。不存在至少两个有实际争议的国家时不开启。触发要求大顺或靖海第三章已进入，朝鲜礼仪关系或东明主体自主产生可观察变化。关键资源是正统性、海贸、自治压力、关系和预算。

| ID | 阶段与作答者 | 选择、代价与记录 |
|---|---|---|
| `ywc_crisis.1` | 请愿：SHU/JHG 提出共同外交称谓 | 提议平等贸易、各自承担使团费；或主张等级礼制，得到保守派支持却抬高他国拒绝概率。记录不可同时满足的核心条款 |
| `ywc_crisis.2` | 主对手：JHG/SHU 回应 | 接受谈判但要求关税与航行权，需主张方让利；拒绝称谓变更，保现状却增加海贸摩擦。对手灭亡则改成本国商会对既有条约的回应 |
| `ywc_crisis.3` | 第三方：KOR 自行回应，DMG 有条件回应 | 朝鲜可接受对等使节、坚持传统礼仪但独立外交、或拒绝加入；东明可争取贸易席位或观望。回应不得改变朝鲜独立地位或东明现有宗主关系 |
| `ywc_crisis.4` | 财政：各签约方审议使团与关税预算 | 共筹互市和使团，花费与市场接入挂钩；缩成礼仪宣言，低成本但不改善实际贸易。无资金的国家默认缩小承诺 |
| `ywc_crisis.5` | 临界点：SHU/JHG 处理拒绝或反对运动 | 删除排他称谓、保留经贸条款以争取妥协；坚持原案，激化关系并使国内保守派动员。战争中仅可先搁置军事相关条款 |
| `ywc_crisis.6` | 结算：实际签字国各自确认 | 多方平等协议需至少两国明确同意、预算与关系可行；有限妥协只处理使节或关税；破裂留下有时限的外交与贸易余波 |

协议反馈 SHU 朝廷与海贸章节、JHG 宪制与护航章节、KOR 身份章节、DMG 海贸章节。朝鲜拒绝不阻断 SHU 与 JHG 的有限协议；东明未参加则不产生该国条约效果。已存在更高优先级的战争或附庸变更时，结算只记认可行的民事条款。

## 危机二：黑水边疆

日志：`ywc_je_crisis_blackwater`；事件 `ywc_crisis.7`—`.12`。北清 NQG 为默认持有人，大顺 SHU、喀尔喀 MGL、俄国和日本在实际边境、商路或影响范围相关时作答。北清灭亡但争端存在，由大顺持有；仅剩一个合格国家则不开启。触发要求北清第二或第三章、黑水边防与商贸之间出现压力，并有至少一个可回应邻国。重点是给小国可支付的边防选择，不凭一次事件制造列强战争。

| ID | 阶段与作答者 | 选择、代价与记录 |
|---|---|---|
| `ywc_crisis.7` | 边民陈情：NQG/SHU 提出护路与测界 | 设共同测界委员会，需官吏和对方同意；单边加强哨所，增军费并提高警戒 |
| `ywc_crisis.8` | 主邻国：SHU 或接壤者回应 | 接受边市与巡逻议案，取得通商利益并承担护路费；拒绝，保战略自由但关系恶化。无相邻国则改为贸易对象回应 |
| `ywc_crisis.9` | 外部势力：俄国、日本、MGL 中合格者回应 | 可提供限期商路保证、要求优惠准入，或不介入；MGL 保有独立判断。未接触该区域者不凭空进入谈判 |
| `ywc_crisis.10` | 动员：NQG 与参与国核算边防 | 分摊哨所与道路费用，减少摩擦但占预算；优先军备，增威慑也压缩民生与贸易 |
| `ywc_crisis.11` | 边市冲突：各方处理越界扣货 | 赔偿并开放仲裁，财政受损而利于协议；扣留货物坚持主张，短期得利却增加升级风险 |
| `ywc_crisis.12` | 结算：参与国确认边防安排 | 测界互市要求领土现状可确认且双方同意；有限妥协只开放边市；破裂留下边防警戒，不自动重画边界或宣战 |

协议反馈 NQG 军费与铁路章节、MNG 南北商路及独立章节、SHU 边防财政。若路线需要的州已换主，相关玩家收到“新控制者拒绝/愿意重议”的正常外交反馈，事件不得假装旧边界仍然存在。

## 危机三：草原与高原商路

日志：`ywc_je_crisis_inner_asian_routes`；事件 `ywc_crisis.13`—`.18`。卫拉特 OIR、喀尔喀 MGL、西藏 TIB 与大顺 SHU 是核心参与者；浩罕、哈密或其他实际相邻商路国家仅在地图与外交条件支持时加入。卫拉特持有日志，若其不存在则由喀尔喀，再由西藏持有；需要至少两个可交易的国家。触发条件是至少两国第二章开始、关卡重复征费、驿站短缺或牧地通行争议。

| ID | 阶段与作答者 | 选择、代价与记录 |
|---|---|---|
| `ywc_crisis.13` | 商队联名：持有人提出过境路线 | 公示低税路线，降低短期关税；保地方关卡，保收入却扩大绕道 |
| `ywc_crisis.14` | 相邻国：主要过境方回应 | 提供通行照会并分担护路，需预算与关系；要求独家通道，获市场优势却遭其他国家抵制 |
| `ywc_crisis.15` | 本地集团：旗主、寺院与商人表态 | 给地方有限管理席位，减反对而使规则复杂；中央统一征收，执行更整齐但激化抵制 |
| `ywc_crisis.16` | 筹资：各签约国计算驿站、边警开支 | 按实际使用量分摊，需稳定财政；由商团承包，国库轻而可能垄断 |
| `ywc_crisis.17` | 断路：山口、牧场或边市纠纷 | 设仲裁并临时开放替代道，花行政资源；强推本国税则，增加外交风险与地方反抗 |
| `ywc_crisis.18` | 结算：签约方确认通行权 | 多边商路须至少两国有真实接壤或市场接入且出资；否则达成局部互市或无协议，不赠送铁路与所有权 |

协议反馈 OIR 伊犁财路、MNG 南北商路、TIB 康青盟约、SHU 西部边防。每国只承担自己的护路账；不在同一市场也可以签限量边贸，而不能获得全市场接入奖励。

## 危机四：南洋航路

日志：`ywc_je_crisis_south_seas`；事件 `ywc_crisis.19`—`.24`。靖海 JHG、东明 DMG、兰芳 LAN 为核心参与者；西班牙、荷兰只有在与相关港口或海域实际接触时参加。靖海持有日志；若其不存在，则东明、再兰芳接替。触发要求两国有活跃海路，且护航费、港口准入或荷兰对兰芳的主张引发矛盾。东明和兰芳的规模与主体身份严格按当前状态判定。

| ID | 阶段与作答者 | 选择、代价与记录 |
|---|---|---|
| `ywc_crisis.19` | 商船申诉：持有人提出护航与港规 | 公开统一港规，花行政费并约束本国商行；保个别特许，维护既得收益但刺激走私 |
| `ywc_crisis.20` | 主对手：JHG/DMG/LAN 中相关国回应 | 签互认船照，需让出部分关税；拒绝并自费护航，保控制而增成本 |
| `ywc_crisis.21` | 外部海权：西班牙或荷兰有条件回应 | 接受互市准入、要求优先权或退出谈判；兰芳可拒绝荷兰单方面保护而寻其他保障，不自动脱离实际宗主关系 |
| `ywc_crisis.22` | 船队与港库：各国核算投入 | 分摊巡航与港务费，海路更稳但挤压预算；商行自备，国库轻而保障不均 |
| `ywc_crisis.23` | 扣船与保费争议：各方处理升级 | 仲裁并退还争议费，损短期收入；扣船施压，可能提高收益但恶化关系与海贸 |
| `ywc_crisis.24` | 结算：实际签约方确认航路公约 | 多边公约须至少两国承诺港规与可支付护航；否则局部船照互认或无协议，不给予免费舰队 |

协议反馈 JHG 海商与护航、DMG 福建贸易与主体谈判、LAN 婆罗洲外约。若某国在危机中丧失港口，其承诺转成待复议条款，其余国家仍可达成有限协议。

## 危机五：太平洋自治争议

日志：`ywc_je_crisis_pacific_autonomy`；事件 `ywc_crisis.25`—`.30`。新明 NMG 与墨西哥是必需双方；美国、大顺 SHU、靖海 JHG、北清 NQG 只有在贸易、外交利益或移民联系存在时回应。新明持有日志；新明或墨西哥不存在、双方已不再有可争的主体关系或领土争议时不开启此危机，改由新明第三章的普通外交收束。触发要求新明第二章财政协定破裂或第三章已进入，同时墨西哥有能力应答。自治前途由主体制度、政治行动和外交关系决定。

| ID | 阶段与作答者 | 选择、代价与记录 |
|---|---|---|
| `ywc_crisis.25` | 自治请愿：NMG 向墨西哥递交条款 | 要求限额税权与地方任命，需保证汇缴；提出更广自治，获本地支持却提高墨方拒绝概率 |
| `ywc_crisis.26` | 宗主回应：墨西哥独立作答 | 接受有限财政与防务分担，换稳定税源；拒绝并维持现行关系，保中央权力而提高自治压力 |
| `ywc_crisis.27` | 第三方：美国与有实际联系的东亚国家回应 | 可给予公开商业支持、谨慎观望或要求投资优先；所有第三方只影响谈判筹码，不能替新明决定独立 |
| `ywc_crisis.28` | 防务账本：NMG 与墨西哥核算海岸安全 | 按约共同支付，增强防务但减少本地财政；各自防务，保自由却增加边界摩擦 |
| `ywc_crisis.29` | 土地与迁居争议：本地议会回应 | 建混合仲裁，花行政费且安抚居民；让投资者先行，获资本却扩大身份与土地冲突 |
| `ywc_crisis.30` | 结算：NMG 与墨西哥分别确认 | 双方同意且财政可行则稳固自治；只同意税或防务则限期妥协；破裂形成政治与外交行动窗口，不自动独立或割地 |

协议反馈 NMG 全三章及既有墨西哥联邦路线；SHU/JHG/NQG 只收到与其真实联系相称的贸易和移民反馈。若墨西哥或新明在六节中灭亡，危机直接进入“无法继续谈判”的无协议结局，避免把新主权状态改回旧设定。

## 共同结算与超时

五条日志只能在自己的六号事件完成后写入结果。每次参与国回应保存国家、答复与有效期限；不能因界面重复打开重复收费或重复加关系。玩家拒绝后，其他国家仍可签允许的缩小协议。AI 未能在限定时间回应时按其国力、关系与利益计算“接受有限条款”或“观望”，并在日志中明确显示原因；灭亡国家的答复为“无人代表”。若已发生大战、控制权变更或条约失效，结算阶段只处理现存可执行承诺。所有危机余波须有期限，重新谈判须走正常外交，不循环刷新同一危机。

| 危机 | 多边协议所需的共同条件 | 有限妥协 | 破裂后的持续问题 |
|---|---|---|---|
| 天下名分 | 至少 SHU/JHG 中的提案方及另一国确认称谓、商税和使团账 | 两国船照或礼仪互认，未签国不受约束 | 正统性争论、港口摩擦与国内派争 |
| 黑水边疆 | 争议边界双方同意测界，承担边市和哨所费 | 单一边市开放或互不扣货 | 警戒与补给费用，允许日后重议 |
| 草原与高原 | 至少两个真实通行国认可税则、驿站与护路分摊 | 仅相邻两国的季节互市 | 绕道、重复征税和地方抵制 |
| 南洋航路 | 至少两国确认港规、护航费和船照权 | 单一航段或双边船照互认 | 航运保费、扣船争议及商业信任下降 |
| 太平洋自治 | 新明与墨西哥都确认税权、防务和任命范围 | 限期财政或防务分担，未决自治议题仍可见 | 自治政治运动与宗主关系紧张，后续仍走正常外交 |

日志在最后事件向所有现存参与国分别显示其所签条款、支付责任、期限和未解决问题。非签约方不获得协议收益或义务；同一国参与多场危机时，重叠的贸易和关系修正按各自期限与上限结算，不能靠反复签约堆叠。
