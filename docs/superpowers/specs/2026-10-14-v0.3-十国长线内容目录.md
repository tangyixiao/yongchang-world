# v0.3「叶公好龙」十国长线内容目录

日期：2026-10-14
用途：确定十国全战役内容的生产目录、独立矛盾与第一批可实施内容卡。与[版本设计](2026-10-14-v0.3-叶公好龙设计.md)、[总实施计划](../plans/2026-10-14-v0.3-叶公好龙总实施计划.md)配套使用。这里是已锁定的新增内容设计预算，不是已实现或实机可达的统计。本轮按用户要求使用 subagent team 实现并执行静态与离线回归，不启动 Steam、游戏或游戏 UI；真实战局、存档加载与长期平衡实机证据均保持未执行，只有未来另行授权后才采集。

## 1. 范围与计数

十国各安排九条长线，共 **90 条命名长线、至少 720 个新增独立事件、180 个新增日志**。下表每条线的“事件/日志”是已分配的最低生产预算，各国均为 72/18；新增分支超过预算可以保留。已存在事件的改名、重复通知、同一事件不同选项、翻译条目和通用可重复弹窗不计入新增独立事件。把一个既有日志拆成几个无独立目标的壳条目，也不能据此达成新增日志预算。

预算不要求每条线都采用八事件、两日志的结构：本目录实际使用 6、8、10 个事件及 1、2、3 个日志的组合。日志必须有可操作目标，事件必须有独立矛盾、参与者行为、局势回应或结果。新增预算之外，旧三十章继续接受盘点、重写、去重与承接修补；旧内容不能冒充新增内容。

实施顺序是 **SHU、DMG、KOR → JHG、LAN、NMG → NQG、OIR、MGL、TIB**，三组都覆盖全战役。每国的“奠基、扩展、韧性”是议题层次：通常在约 1836—1870、1870—1900、1900—1936 集中出现，但由实际局势、前序结果与国家能力开启，不能按年份强迫转型。未工业化、保守延续、改革撤回、国家衰退、长期和平都有后续。实际战争发生时再使用动员分支，不预定战争、共和、独立或工业化。

`MGL` 是喀尔喀运行 TAG；历史设计所用 `MNG` 和现有 `ywc_mng_*` 命名保留兼容，不能把它与新明 `NMG` 混淆。目录 slug 是全局唯一设计标识；运行事件 ID、JE 键、状态字段在对应内容卡落地时登记，不用目录 slug 覆盖旧标识。

输入文件统一为 `data/content/v03/countries/<小写运行TAG>.json`；`key` 为 `country_<小写运行TAG>`，因此喀尔喀使用 `mgl.json`、`country_mgl`，事件 namespace 仍为 `ywc_mng`。新国别事件统一占用各国既有 namespace 的 `.1000`—`.1999`；目录顺序不能参与计算 ID，明确区间写入 `id_registry.json`。本文件三张首卡各锁定 `.1000`—`.1009`，其余长线在实现前按显式区间登记。

## 2. 全目录共同规则

- 每行“真实行动/状态”必须接入法律、政府组成、集团力量、机构、建筑就业、生产方式、预算、商品供给、市场接入、实际外交关系等游戏事实。少量专属状态记录承诺、契约、例外和结果，不能另造一个分数替代真实治理。
- 事件可承诺、补偿、设试点或开启谈判；法律仍由立法系统推进，建筑仍要投入建设与就业，主权与条约仍要对方同意。选项不能凭空给予领土、独立、永久增长、真实不存在的伙伴或免费的保护。
- 后期线读取前期的分类结果，或依据当前国情承认“此前已自行完成”。前期未走某线时，后期可从旧制延续或当前制度进入；所有九线不排成一条必须依次完成的队列。
- 互斥分歧指同一阶段不能同时兑现的政策承诺，不要求永久锁死。反悔必须触发成本、补偿、他方回应或重新审议。成功、局部落实、撤回、失败均产出后续入口。
- “连接国家”是可参与对象；缺席、灭国、关系改变或玩家选择不合作时，改走本国或替代伙伴内容。外国应答只对自己的投入与条款负责，不由发起国单方面判定成功。
- 人物按角色与利益集团生成，不绑死跨百年的历史人物。人物离场后交接给继任者；除非有独立的继承矛盾，不把死亡变成断链。
- 后期和平线与战争线共享同一条预算中的不同事件；目录只登记独立定义一次。单局不会看到全部 720 个事件，互斥事件数量和典型单局可见范围要另记。

## 4. 第二批：宗藩、公司与海贸网络

### 6.1 SHU《天下田粮，谁家账册》

**设计标识**：`v03_shu_fiscal_register`。事件锁定 `ywc_shu.1000`—`.1009`；两 JE 键为 `ywc_je_v03_shu_register_pilot`、`ywc_je_v03_shu_fiscal_settlement`。登记后先查重，不能覆盖既有 `ywc_shu.100`—`.114`。下表 E1—E10 依次对应 `.1000`—`.1009`。

**参与者**：户部官员要可核账收入；地方缙绅要认可供役与旧免；军镇要先领欠饷；海商愿预付但要求稳定税则；被重复征役的民户要可申诉。集团不等同于所有本地人口，事件具体承担者按实际州就业和集团映射选取。

**入口与已有内容**：SHU 存在且拥有至少一个可执行行政的州，尚未完成此线；由旧朝廷三席内容提出，或玩家主动开启。现有税法和官僚体制先进时，以《已经在册的田粮》替代开场段落并进入执行审查，不能要求倒退法律重做。只存一个试点州 scope；州丢失时保留承诺并允许选新州，已付不可退的清查费用仍保留。

**JE 1《把田粮写进同一本册》**：玩家在自己拥有、未被占领的州里选择试点；目标是补足行政与供给、确定查核/地方分担方式，并完成两次相隔至少三个月的核账。首版门槛采用试点官署就业率 ≥80%、纸张投入品无短缺、全国行政余额 ≥0；若开局缺少官署或相关投入，则建设与采购本身是实际目标。清查新增官署不是强制数量，已有能力能直接满足。地方合作路线可以用较低中央覆盖换分税义务，不能用按钮直接消除真实税收浪费。

**JE 2《新税册要付旧承诺》**：JE 1 有分类结果后开启；检查税册是否被用于军饷、地方供役或商税替代。玩家为试点划定中央查核、地方分担、旧额封顶之一，维持六个月可支付预算与执行能力。财政观察中“可支付”定义为未破产、未违约、债务未连续三个月增长；不是必须国库全满或全国零税收浪费。战时可改为有限核账并留下延期，不强迫停战。

**专属记录**：查核模式三选一；试点州；承诺的补偿/分税有效期；延期原因；结果为中央核账、地方分担、有限旧额、撤回失信之一。真实税收、建筑与法律不复制成进度分数。费用按开启时的周财政收入折算：一次清查为一周收入，分两次扣付；地方补偿为十二个月合计两周收入。若引擎无法直接读取该口径，实施者先用现版官方脚本支持的收入基数确认并登记，不能悄悄换成各国相同的固定金钱。

**跨线反馈与验收**：军镇线读取军饷由谁支付；海关线读取预付和咨询承诺；省朝线读取留用份额；JHG 对贡赋报价不能预设 SHU 财政稳定。验收至少覆盖先进法律开局、旧制封顶、补偿后财政恶化、试点失州、长期和平、真实战争六种情况；确认启动资金/成本不重复、失地不抹除债务、旧三席结果不被覆盖。

### 6.2 DMG《共同臣民的名字》

**设计标识**：`v03_dmg_common_subjects`；事件锁定 `ywc_dmg.1000`—`.1009`；两 JE 为 `ywc_je_v03_dmg_public_qualification`、`ywc_je_v03_dmg_compact_review`。本线重写既有《共同臣民》《法律上的本地人》的承接时，旧事件只是前序或跳转，不计入这十个新增定义。下表 E1—E10 依次对应 `.1000`—`.1009`。

**参与者**：朱氏王廷要可征税、可守边界的共同忠诚；明裔军户要求旧服役地位获承认；华商要稳定契约和任官渠道；本地贵族要地区权利；村社和混合家庭要不受任意排除的税务、军职与申诉资格；宗教团体关心公共仪礼和教育。不能把任何一方简单写成整种文化的唯一代表。

**入口**：DMG 拥有北吕宋至少一个州且存在实际多群体政治/身份矛盾，旧契约线已引入或主动开启。相关法律提前改变时，转入落实和任命争议；仅改变政体不自动完成共同资格。若只剩单一文化或缩小到无法呈现原矛盾，保留法律审查与迁入者资格，改写事件参与者。

**JE 1《同一国书上的资格》**：玩家选择一项首轮行政职责（官署、军职或地方税务）作为执行入口，在六个月内形成共同资格或地区保障条款，并使相关岗位实际就业、行政不赤字。国籍/身份读取现版 acceptance、实际任官/从军和政治资格，不能假定某个旧版国籍法等于完全平等。本机官方当前 `00_citizenship.txt` 含 `law_subjecthood` 和 acceptance 机制；实现必须核验其正式触发与可获取数据，再冻结检测定义。

**JE 2《共同义务是否兑现》**：第一份契约有结果后开启九个月审查。共同资格路线必须在法律上允许约定群体从军/任官，且落实官署/军队岗位；地区契约路线不要求全部相同，但须有实际地方执行和双方可用的申诉机制；旧身份路线须公开区分资格并付出安抚与额外分治行政成本。政治代表方面，依法有选举则检查资格与实际代表制度；无选举的咨询王权采用公职资格和共同任命章程，不虚构议会选票。

**费用与兑现**：双语登记/申诉所十二个月合计一周开启时财政收入，并占用行政能力；旧军户补偿十二个月合计一周收入；任官与军队目标依真实建筑就业与法律，无免费官员。三条路径互斥记录 `common_qualification`、`territorial_compact`、`status_orders`，可经后续重议改变。接纳程度和就业是不同事实；有新法而没岗位，不能写“已进入官署”。

### 6.3 KOR《军门、税簿与新官署》

**设计标识**：`v03_kor_military_accounts`；事件锁定 `ywc_kor.1000`—`.1009`；两 JE 为 `ywc_je_v03_kor_military_audit`、`ywc_je_v03_kor_service_settlement`。本线用“供应与指挥如何持续”区别于 SHU 税基查核和 DMG 资格契约。下表 E1—E10 依次对应 `.1000`—`.1009`。

**参与者**：王廷希望统一指挥而不能无限加税；军门要稳定粮饷；各道官员要保留预算自主；士林要监督军费与征发；普通服役者和家庭关心负担；港商/工匠愿提供装备却要求可支付合同；译学生和外来教官各有雇佣边界。

**入口**：独立 KOR 存在且有军队或防务计划。进入后实际成为属邦时改写自主范围和对外教官选项，保留内部供应改革；不能把身份变化直接视为灭国。无现役军队可走有限边警/旧军核额，不强迫扩军。军费和装备已经完善时从审计旧军额与地区权责进入。

**JE 1《点清军额与军粮》**：选择王廷常备、各道分担、限额旧军三种方案之一，登记已有军队、选定供应地区并进行半年观察。常备方案需正常推进相应军队法律、真实兵营就业率 ≥80%、军事工资不低于中档且军用商品无短缺；各道方案不强迫相同法律，但要实际部队/边警与可支付分担；限额旧军可少扩或不扩军，以旧制度可负担供给完成较小目标。三者都不得只检查营数不看就业。

**JE 2《谁来维持新的军门》**：核额后再观察九个月；全国行政余额 ≥0、未破产/违约、登记供应支出已支付、所选军制仍满足自身承诺。和平走训练、轮值、退役与采购审查；真实战争时检查动员供给并允许缩小非必要训练。短缺出现时进入采购/生产/缩军路径，不要求必有外国交易伙伴。

**费用与状态**：核额一次一周开启时财政收入；教官十二个月合计一周收入，仅在真实雇佣对象和条件存在时可选；旧军户转职支持十二个月合计一周收入。采购不直接生成装备储备，而是短期财政义务、真实贸易/生产与短缺状况；不能免费获得科技和军队。记录供应责任 `court_supply`、`provincial_supply`、`limited_legacy`，承包/自制选择、缩军承诺和分类结果；实际军队、商品和预算不复制为分数。
