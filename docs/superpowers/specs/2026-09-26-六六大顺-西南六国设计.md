# 《永昌世界》v0.2「六六大顺」设计：西南六国

日期：2026-09-26
阶段：版本设计与实施依据。承接 v0.1 十国开局、大型内容包三章战役与 v1.0「受命于天，既寿永昌」先行层（天命霸权）的既有接口。

## 1. 版本定位

v0.1 完成了十国垂直切片；西南十四国此前只有地图与开局存在感（"其余国家先达到正确开局和一条核心日志"）。v0.2「六六大顺」给西南六国各补**一条核心日志、三个事件**，让大顺的西南边疆从背景变成可玩的对局：茶马、茶山、印经、练军、土司会议与两属外交——六个位置、六种活法，故名"六六"。

主线约束继承：不发核心、不免费领土、不强制改土归流；拒绝与顺从都有代价；小国规模保持压力。

## 2. 六国与三条线

| 国家 | 定位 | 日志 | 三节 |
|---|---|---|---|
| LJG 丽江国 | 大顺藩属·茶马商道（木氏） | `ywc_je_sw_ljg`《茶马引盐》 | 引盐之议 → 藏商入城 → 木氏继嗣 |
| SIP 西双版纳 | 大顺藩属·车里宣慰 | `ywc_je_sw_sip`《十二版纳》 | 茶山之约 → 缅使西来 → 十二版纳分担 |
| DER 德格王国 | 康区主邦·印经院 | `ywc_je_sw_der`《印经银钱》 | 印经院的债 → 护商之约 → 僧俗之争 |
| GYL 嘉绒联盟 | 大顺缓冲·戎马联盟 | `ywc_je_sw_gyl`《戎马屯田》 | 屯田与牧场 → 练军之请 → 盟主之争 |
| SHD 掸邦联盟 | 大顺缅甸之间·土司邦联 | `ywc_je_sw_shd`《三十七土司》 | 土司联席 → 设官之请 → 茶叶与罂粟 |
| ARA 若开 | 英国保护·缅甸缓冲 | `ywc_je_sw_ara`《两属之邦》 | 驻扎官的账单 → 缅甸流亡者 → 稻米专约 |

事件编号 `ywc_<tag>.1`–`.3`（各国首个事件命名空间）；每节前两节为议题与外部回应，末节为本线结算，写 `ywc_sw_<tag>_resolved`/`_failed`，日志照此收束。

## 3. 机制契约

- **入口**：六国日志由 `ywc_regional_countries.txt` 的国家块在开局挂载（先 `ywc_reset_shared_variables` 再挂日志，满足共享变量初始化门禁）。
- **效果词表**：国库、限时修正（八个新增：茶马新章、互市开城、护商之约、练军之效、摊派之累、烟祸蔓延、稻米专约、流亡之累）、关系（大顺/英国/西藏/缅甸/德格按需）、事件标记；**不触碰**共享正统性/海贸/自主压力变量（区域国家保持轻量），不设置路线成功失败。
- **关系对象**：SHU（宗主与商路）、GBR（若开的保护国）、TIB/DER（高原商道）按事件显式指定。
- **可达性**：journal 开局挂载即满足；18 个事件全部由各线 journal 的月度脉冲按序投递。

## 4. 实现与验收

- 清单 `data/content/southwest_event_catalog.json`（18 事件双语）为唯一实现输入；`tools/build_southwest_content.py` 生成事件脚本与双语文案，`--check` 防漂移；journal 追加、开局挂载与修正注册由一次性 emitter 产出静态内容。
- `tools/ywc_southwest_check.py` 与 `tests/test_southwest_content.py` 校验清单、生成新鲜度、六线三节链路、修正声明与双语覆盖；可达性计数更新为 events=323 / journals=86。
- 静态门禁通过不等于实机验收；西南节奏与 AI 行为仍按手册门槛执行。
