# 新明：以已履行的固定汇款争取市场管理权

## 问题与证据

现有固定汇款协议让真实墨西哥作答，形成 60 个月的付款、欠款和 +5 行政力，但不改变原版外交权利。十国目录要求自治税务线中换取的自治权具体可辨。新明开局是墨西哥保护国；本机原版保护国行动未列收入转移，原版减付行动又排除保护国，因此不能假设默认有贡赋可减。

可选的实际权利是让新明成为自己的市场拥有者。本机原版 `common/diplomatic_actions/36_subjects_grant_own_market.txt` 使用 `market_owner = second_country`，原版埃及保护国历史与 `the_grand_collapse_events.txt` 使用 `create_diplomatic_pact`。这是静态词汇与用法证据，不是本模组或引擎经济结果的实测。新市场会脱离墨西哥的共同市场，可能改变供给和贸易；不改变保护国身份，也不承诺额外建造、市场繁荣或独立。

## 选择和合同

固定汇款按原合同独立签署，不重解释旧 `right = 1`。在至少一期实际汇款已入账、当前账款无拖欠且原墨西哥仍为实际直属宗主时，新明玩家可通过原版决议界面自愿询问是否获得独立市场；如果双方不再共享由墨西哥控制的市场，或已有相关市场条约，则不可发出。询请不收新费用，不修改已签月额或欠款。该决议在日志结案后、合同仍有效时也可使用。

新明主动发出的询请保存双方具体国家、原市场对象、固定汇款的代际、月额、期限以及独立的询请序号和三个月限期。实际墨西哥收到带条款的答复事件，接受或拒绝；对方缺席、关系变化、原市场对象变化、到期或不再有当前无欠款合同均不得接受旧询请。无须为了争取此权利放弃本地方案；已签汇款义务及以前的付款不因拒绝、离线或自主权结束而免除。

接受时仅建立本模组独立命名的双方外交条约，参照原版从墨西哥指向新明并设置 `market_owner = second_country`；不移除原版或玩家已有条约。条约不设强制不可解除期，可由任一方按规则解除。它只在相同汇款代际、实际直属关系与账款无欠款等条件仍成立时维持；原版文档说明维护条件失败通常下一 tick 解除，故不声称变更当日即时停权。账款补缴后须重新询请并取得新答复，不能自动重建。合同结束或身份变化时，条约应按维护条件终止；欠款仍独立保留。市场重组和商品变化以引擎为准，不推测移除后一定重回哪个市场。

询请限时及六个月重试冷却用于避免旧答复或反复打扰；主体变化立即取消未签询请。每次调用都再次校验对方和合同。普通日志事件队列不因决议或外部答复而重排。

## 验收边界

必须在源码模型中验证有/无合同、未付款、对方拒绝、接受、旧答复、合同变化、欠款和补缴、失去直属关系、国家对象消失重建、已有市场条约、冷却以及日志结案后的申请。模型仅记录条约和明确的市场拥有者转换，不模拟商品、原版外交 UI、真实日调度或贸易后果。须校验双语与生成器，独立审查并冻结源码后运行跨国回归。用户禁止启动 Steam、游戏、启动器及 UI；M2 和完整 v0.3 在所有其他门槛完成前仍未完成。
