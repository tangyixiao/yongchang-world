# 北清港口协议的州级贸易便利

## 背景与选择

当前已签的外国港口协议保存真实伙伴、北清港口州、市场、名义泊位份额、关税条款及期限；它尚不改变经济数据。目录要求港口就业、贸易、税率与真实伙伴答复，并区分多方泊位、单方优惠和高税自守。

保留纯记录最安全但没有经济效果；声称精确分配双边泊位、只对伙伴设置税率则缺乏已核实的游戏脚本接口。选择第三条：以原版已有州修正表示港口管理和进口贸易便利，同时明确它影响该州所有贸易中心，不保证某一伙伴独占泊位，也不自动开辟贸易线或派舰。

## 实际效果

仅在捕获的北清港口州和伙伴市场等对象仍满足原合同条件时，按月给予一个月的州修正：

- 名义泊位条款 0.5、税则代码 1：州贸易容量 +20%，州进口关税上限 -10 个百分点。
- 名义泊位条款 0.6、税则代码 1：州贸易容量 +30%，州进口关税上限 -10 个百分点。
- 未知条款不产生任一新修正；两种修正互斥，不改变原报价或真实答复。

本机原版 `common/static_modifiers/02_event_modifiers.txt` 的 `economic_concessions` 包含 `state_trade_capacity_mult` 和 `state_tariff_import_add`；`common/modifier_type_definitions/modifier_types.md` 说明 `state_` 修正流向州，`00_modifier_types.txt` 定义了这两种类型。原版 `portuguese_colonialism_modifiers.txt` 与对应事件展示了在州作用域添加贸易容量修正；`localization/english/modifiers_l_english.yml` 将进口税修正解释为进口贸易中心的最高关税，并非逐国关税率。原版 `common/on_actions/ip4_on_actions.txt` 也展示了在州所有权变化的 state root 子 action 中移除修正。以上是静态词汇与用法证据，不是本 mod 通过引擎解析或游戏验收的证据。

## 生命周期与验收

签约生效时即时应用；每月重新校验合同，暂停、到期或不支持条款时移除。原州变更所有者时立即从该州移除；恢复同一对象后下一次月检可重新应用。已签合同在事件线结案或主体变化时仍按既有账本持续；任何旧到期事件不得移除新合同对应的修正。除州所有权变化和合同到期回调外，伙伴或市场状态变化在下一次月检处理。

离线测试必须覆盖未接受不授益、两个条款及修正互斥、精确捕获州、州易主即时移除、市场与伙伴失效及恢复、期限到期、旧端点重放、签约延续与源码生成。仍须诚实说明不存在物理泊位份额保证和伙伴专属关税。
