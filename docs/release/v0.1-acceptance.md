# Yongchang World v0.1 acceptance record

## Baseline and scope

This release candidate targets Victoria 3 **1.13.11 (Matcha)**. It contains the ten-country content slice for SHU, JHG, DMG, NQG, OIR, MNG, TIB, KOR, LAN, and NMG. NMG remains a contested Mexican autonomous subject rather than an instant independent American empire.

There is no planned 1900—1950 political ending: the scenario provides routes and pressures, not a predetermined final political outcome.

没有预定1900—1950政治结局，玩家的路线选择和外部压力共同决定后续局势。

## Verified without desktop interaction

- 96 Python tests pass and `tools/ywc_check.py` passes.
- Hidden launches mounted the mod at `E:/Victoria3 Mod/yongchang_world` and matched `1.13.*` to 1.13.11 across multiple probe runs (`artifacts/observe/*/run.json` records the mount lines verbatim).
- Root cause of the earlier "isolated `-userdir` runs never mount the mod" observation was found and fixed: the game rejects a UTF-8 BOM in `content_load.json` and silently falls back to "all DLC enabled, no mods". The observation runner now writes compact BOM-free JSON and, after each launch, records `mod_mount`, version-match evidence, observed DLC mounts, ownership-backend state, and whether the observed DLC set matches the requested config.
- Run `artifacts/observe/none/47` is a verified hidden launch with the mod mounted and zero DLC data mounted, matching the no-DLC config (`dlc_state_matches_config=yes`). A later `wave/11` run re-verified the full field set: mod mounted and version-matched, while `expected_mounted_dlc=[dlc018_ep2]` versus `observed_mounted_dlc=[]` honestly records `dlc_state_matches_config=no` under an unavailable ownership backend.
- Platform limit proven by probes (`artifacts/observe/dlc-probe`, `dlc-id-probe`, `sphere/23`, `all/11`): for a directly launched executable the game ignores `disabledDLC` entries (with pops_id or steam_id) whenever its ownership backend reports ownership, and the ownership backend flips between "all 17 owned" and "none owned" across launches minutes apart. Single-DLC configurations (sphere/charters/wave) therefore cannot be reproduced without the official launcher UI and stay pending rather than being claimed.
- Added `yongchang_world/common/diplomatic_actions/ywc_diplomatic_actions.txt`: a minimal verified pact action `ywc_nmg_autonomy_negotiation` (New Ming proposes autonomy negotiations to Mexico while subject and carrying `ywc_je_new_ming_mexican_chain`, which is added to NMG at start; acceptance resolves that journal, which no event set before). Hidden launches parsed `common/diplomatic_actions` with zero unknown trigger/effect findings, zero localization errors, and zero database conflicts; the bilingual loc files carry a UTF-8 BOM like the existing ones.
- The in-game smoke suite gained `ywc_nmg_autonomy_action_ready`, a read-only check that NMG carries the chain journal or has already opened the negotiation. The engine strings confirm `tools/scripted_tests` as the exact path it queries and expose a `scripted_tests after` command, so the suite's location is correct; running it still requires an entered campaign, and no run of it has been executed yet.
- The smoke collector reports clean logs after the hidden launch.
- The native `scripted_tests` release smoke suite is included at `yongchang_world/tools/scripted_tests/ywc_release_smoke.txt`; it is ready to run inside an entered campaign and does not alter the campaign.
- The matrix shape is present in `artifacts/observe/matrix-summary.json`, but its runs are marked `not_run_no_desktop_interaction`.

## Known limits

- The mod does not change underlying map geometry; several regional starts deliberately use Province subsets.
- NQG population, DMG Manila claims, JHG Taiwan boundaries, and NMG's Mexican subject relationship are enforced by the scenario data.
- The 15-run, three-seed, 1846/1866/1900 long observation matrix and visual country-selection checks remain manual acceptance work. They are not represented as completed here because no desktop switching, screenshots, or UI clicks were performed.
- The three DLL families used by the installed game compatibility layer were not modified by this repository.
