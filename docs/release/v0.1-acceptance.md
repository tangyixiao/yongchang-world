# Yongchang World v0.1 acceptance record

## Baseline and scope

This release candidate targets Victoria 3 **1.13.11 (Matcha)**. It contains the ten-country content slice for SHU, JHG, DMG, NQG, OIR, MNG, TIB, KOR, LAN, and NMG. Here `MNG` is the scenario-facing Khalkha name; the runtime country-selection and observation tag is vanilla `MGL`, because vanilla `MNG` is Minas Gerais. NMG remains a contested Mexican autonomous subject rather than an instant independent American empire.

There is no planned 1900—1950 political ending: the scenario provides routes and pressures, not a predetermined final political outcome.

没有预定1900—1950政治结局，玩家的路线选择和外部压力共同决定后续局势。
