## Visual clothing boundary

The base game assigns both Han and Manchu cultures `ethnicities = { 1 = asian }` and `graphics = east_asian`, but the direct ruler-clothing rule is in `gfx/portraits/portrait_modifiers/01_clothes.txt`: `chinese_imperial_clothes_trigger` gives an own-country Han-heritage monarch under monarchy or social monarchy the `chinese_imperial_outfits` portrait modifier; it also has a separate `home_country = c:CHI` branch that bypasses the Han-heritage check. That vanilla imperial outfit reads as Qing-style. Pop clothing uses the game's Chinese low/common outfit modifiers by strata.

The royal-identity gate covers Han-heritage own-country rulers and heirs in SHU/DMG/NMG/MHG while the country has monarchy or social monarchy. Clausewitz explicit `REPLACE:` overrides preserve all original predicates in `chinese_imperial_clothes_trigger` and `chinese_court_clothes_trigger`, adding only the narrow royal-identity exclusion. This exclusion remains active with or without EACR, so the four houses do not regain vanilla Qing imperial clothes or ordinary court-cap candidates. A separate fallback gate requires EACR to be inactive before the two weighted vanilla fallback selectors can apply. `00_ywc_EACR_compat_trigger.txt` follows EACR's documented compatibility interface: its `zz_EACR_mod_compat_trigger.txt` uses `REPLACE_OR_CREATE:EACR_is_active_trigger` to change the default `always = no` to `always = yes` when EACR is loaded.

The EACR behavior was checked against the official [1230james/vic3-east-asian-clothes source at fixed commit `8b9083d00ca10c58683664b6d2970ed019899445`](https://github.com/1230james/vic3-east-asian-clothes/tree/8b9083d00ca10c58683664b6d2970ed019899445). Its `EACR_st_owner_is_CHI_han` covers CHI, TPG, or a non-Qing owner with a primary culture matching its Chinese-culture predicate (Han or Sinosphere, excluding Korean, Vietnamese, and Japanese heritage). Its portrait selectors cover particular monarchs, heirs (including regency handling), subject royalty, and court officials; population selectors also have role/strata conditions, so this is not a claim that every Han person receives Ming clothing. Its Ming outfit genes map women to `female_outfit_chinese_01_high`, not a Ming-specific female outfit. Some royal headgear reuses a Korean model, and the hairstyle is a general East Asian topknot; the outfit set is therefore a limited Ming-style treatment rather than a complete Ming reconstruction. The companion is installed separately and its assets are not packaged here. The pinned official source repository is an alternative acquisition source if the Workshop item is unavailable.

Companion installation evidence: the verified checkout at `refs/eacr-companion` is pinned to the commit above and metadata version `1.0.4`; the local mod junction points to that checkout, with 379 model files verified. Launcher SQLite readback confirmed the local mod is `ready_to_play`, metadata is applied, and EACR is enabled in both playsets that have Yongchang World enabled. `PRAGMA integrity_check` returned `ok`; the pre-change database backup is `artifacts/launcher-backup/launcher-v2-20261013-175222-990441.sqlite`. This proves local installation/registration only; the game has not been launched and no portrait has been visually checked.

When EACR is inactive, `yongchang_world/gfx/portraits/portrait_modifiers/ywc_han_royal_appearance.txt` injects weighted candidates for vanilla `chinese_court_outfits` and `no_headgear` (`add = 2100`); weighted selection does not guarantee either candidate will be chosen. No hairstyle override remains. These templates provide a limited vanilla court fallback, not complete Ming-style Han clothing, and no new Ming-era outfit assets are included. Focused tests execute the shipped gates over a role/country/law/EACR matrix and, when a game root is available, compare replaced predicates against vanilla. The game has not been launched and portrait appearance has not been verified.
