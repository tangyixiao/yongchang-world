## 大顺：军权任用与海关依赖分别交账

`v03_shu_service_compact`《军镇与铨部》，`ywc_shu.1010`—`1017`，8 事件、3 日志。世袭军镇的供饷权和铨部的任用权争同一套人员、预算与命令。专业整编、军镇共约、封顶旧军都可成立，但分别要求适用的军法、军费、实际兵营/官署就业与集团支持。

三个日志分别处理供饷契约的登记和付费、实际任用与供给、连续六个月的继任履约。和平时期仍能检查军费和岗位，不把战争当作唯一推进手段。

| 事件 | 独立争点/行动 |
|---|---|
| 1010 两枚印信的一份调令 | 明确专业任用、军镇共约或限额旧军的责任边界 |
| 1011 军户欠饷与文官空缺 | 财政原型结果改变登记或协商门槛，核查现存军户/官署 |
| 1012 将领的保荐名单 | 军职推荐与实际政府/军队支持相碰 |
| 1013 按营交验还是按镇包供 | 分别检验实际兵营供给和军镇承担条件 |
| 1014 未出征的军费单 | 和平也须兑现军费与供给承诺 |
| 1015 铨部退回的任命 | 再次读取财政和任用选择，处理真实岗位缺口 |
| 1016 军镇请求重议上限 | 已签协议能收缩或重议，不能抹掉已付成本 |
| 1017 下一任仍须照章 | 依当前履约及已成熟的相应观察目标收束 |

`v03_shu_port_treasury`《海关之外的国库》，`ywc_shu.1018`—`1025`，8 事件、1 日志。统一关账、商议分成、旧包税分别面对港商筹资、行政供给和税制约束，不凭空生成贸易或税额。既有商人垫款及军镇协议至少在两个节点影响实际收费或资格。

事件顺序为《一笔港税的三个收款人》《内地账房来查海关》《商人愿垫哪一项》《禁货也在税单上》《船进港而款未进库》《两种关单的通行费》《淡季如何分担》《国库不只靠这一港》。日志持续交验真实港口、相关贸易法律和行政供给；无港或失港时允许缩限/撤回，不能把保留旧例描述成已全面统一海关。

## 东明：土地权与任命权各有执行成本

`v03_dmg_two_land_titles`《两张地契之间》，`ywc_dmg.1010`—`1015`，6 事件、1 日志。军户土地、村社旧权和商业抵押相重叠。混合仲裁、统一契约和旧权划界分别依现行土地法、农业/行政岗位、财政与地方局势兑现，不免费授予法律、土地或人口。

| 事件 | 独立争点/行动 |
|---|---|
| 1010 军户与村社各执一契 | 选择仲裁结构与实际登记成本 |
| 1011 丈量员从哪条田埂走 | 读取共同国书/地区协议，决定参与条件 |
| 1012 商人的抵押契 | 商业契约和既有权利的边界 |
| 1013 赔偿先付给谁 | 实际财政补偿及合法受领责任 |
| 1014 迁居者来补登 | 再次读取资格协议，处理现有居民而非虚构迁入 |
| 1015 土地没有随纸张移动 | 核验持续执行，允许有限结果、受挫或退出 |

`v03_dmg_court_provinces`《维甘与诸邑》，`ywc_dmg.1016`—`1023`，8 事件、3 日志。王廷统筹、共同任命和地方联合都有可执行的职位/预算约束。三个日志分别处理任命权议定、实际职位与地方预算、连续九个月的代表或共任章程复核。选举制度读取实际投票资格；无选举王权读取实际官职与章程，不虚构议席或强制共和。

事件顺序为《王印与地方印在同一封信》《地方愿出多少饷》《任命书送到空官署》《贵族要求列席的次序》《没有选举时如何共议》《防务支出谁能否决》《新任官要不要重签》《诸邑承认哪一种国书》。共同臣民与土地仲裁的选择必须在至少两个节点改变实际门槛、费用或参与条件。

## 朝鲜：教育组织与开港范围各留保守路径

`v03_kor_school_factions`《书院与译学馆》，`ywc_kor.1010`—`1017`，8 事件、3 日志。书院合办、官学统筹和限量译学争的是经费与实际任用；不把焚弃传统教育作为新学成立条件。三个日志分别处理权责经费、真实大学/官署岗位和供给、连续六个月任用及财务复核。

| 事件 | 独立争点/行动 |
|---|---|
| 1010 书院门口的译学生 | 选择合办、官学或限量译学 |
| 1011 先生写在预算边的批注 | 读取军账承诺及窄目标，核定支出责任 |
| 1012 谁来核对译本 | 学术权威与行政核验的职责分配 |
| 1013 官署要人还是要科名 | 真实岗位与教育制度条件 |
| 1014 军账里的旧翻译合同 | 再读未清义务，不重复收费或抹债 |
| 1015 缺纸缺人时先停哪一课 | 供给/就业失效后的收缩与补救 |
| 1016 结业之后是否真的任用 | 观察实际任用，不能用毕业通知代替岗位 |
| 1017 新学不必焚掉旧书 | 按已兑现的相应标准收束 |

`v03_kor_controlled_ports`《海边禁令的例外》，`ywc_kor.1018`—`1023`，6 事件、1 日志。指定港、一般通商和保留禁例的岸市分别读取实际港口、贸易法、行政供给与财政。港口缺席可用真实的较低岸市目标，但不能宣称完成全面开放；不赠送船只、贸易路线或宗属变化。

事件顺序为《同一港口的两张税单》《例外能不能写进港则》《海商与岸上牙行》《海防衙门索取账册》《收回例外之前先算欠款》《下一班船按哪条规矩》。军账履约和译学组织选择至少在两个节点影响实际资格/费用。

## 共同验收约束

- 保留三条 M1 原型与旧 ID/路线。缺少新前序结果、旧存档兼容跳过或集团缺席时使用明确替代语境，不伪造成功。
- 每条线至少两种成立策略、确立/妥协/受挫收束和撤回路径。重要选择由至少两个后续脚本节点实质读取，不能只登记元数据。
- 按共享机制限至三条活跃线、六个可见任务、主事件间隔九十日；领取/释放幂等。三日志有各自操作目标与顺序，不能拆壳凑数。
- 财政成本实际扣款，选项与效果内都检查支付能力；支付失败不推进。已签义务不随退出消失，不重复追收。
- 连续六/九个月观察失效后重置；低目标成熟不能用于高目标结局。等待投递不计失败；真实受阻十二/三十六月有补救与退出。
- 对话弹出后发生失州、战争、财政恶化或参与者变化，仍应有合法重试/退出。触发条件与实际效果的守卫一致。
- 仅执行静态源数据检查和严格脚本子集的离线回归。Steam、启动器、游戏、实际存档、UI、AI、性能及长期平衡验收全部保持未执行。
