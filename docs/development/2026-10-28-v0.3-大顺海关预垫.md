# 大顺海关预垫的期限、追偿与中断恢复

海关借款现在按签订时捕获的正数本金建立十二个历月的等待。国家月度回调只在等待结束且现款足够时归还本金；提前结案、撤回和港口丧失都不免除债务。旧版未偿债务缺少可信的签订日，首次迁移时保守等待十二个月，已有等待不延长；损坏的零、负数或缺失本金不产生付款或收入。

海关和税册商垫分别记录逾期。旧共享逾期修正的归属不能可靠倒推，因此只对可能继承旧海关债的存档保守锁存，不让税册还款提前清掉它；新海关贷款使用独立逾期修正。

1020 的选项和底层效果共同核对当前商议阶段、合格港口、未作答状态、财政和成本。1024 的普通负担选择与失效通知继续使用独立队列；尚未恢复资格时只能等待、缩限或撤回，不能重新启动观察。商人分成路线缺少实际查账权时，1025 提供返回账式协商的入口，保留已付费用和旧债，并在补齐条款后重新观察六个月。它不直接授予缺失权利。
