# v0.3 新明：固定汇款与市场管理权

新明签署原有固定汇款协议并实际支付至少一期后，可以主动向真实墨西哥宗主国请求管理自己的市场。请求时必须仍为直属关系、无欠款，并与墨西哥共同使用由墨西哥管理的同一市场。实际墨西哥可接受或拒绝；答复捕获申请人与接受人、原市场、原协议代际、月额及期限，旧答复不得替后来的协议创建权利。

接受后，脚本创建仅属于本功能的独立双边条约，使新明成为市场拥有者；市场将脱离原共同市场，贸易和供给可能改变。权利只使用原汇款协议的剩余期限，不重开 60 个月；请求时显示的剩余日历月为估计值，精确截止仍由原合同计时。双方都可以解除该条约；出现欠款、合同结束或直属关系失效时，其维护条件失效，按游戏的维护检查处理。已付金额和欠款不受权利结束影响，补缴后须重新请求并取得对方同意。

已观察到的市场对象变化会在月检取消未答复的询请；如果对象在两次月检之间离开后又恢复为同一对象，脚本不能证明中途变化。新明决议的 AI 权重为零，意味着目前只设计玩家主动请求；没有宣称 AI 自然决策可用。

本机原版提供 `market_owner = second_country` 条约及市场作用域保存和比较的源码例子，但尚未找到将市场对象存入持久变量的直接原版例子。本批采用项目已有同类写法，仍待引擎确认。离线测试不模拟贸易结果或真实市场重组；没有启动游戏、Steam、启动器或 UI，也未进行存档、AI、性能与游戏性验收。
