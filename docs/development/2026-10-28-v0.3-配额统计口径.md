# v0.3 内容配额：定义数量与叙事审查分开

完整设计要求新增至少 1290 个独立事件和 342 个日志；纯转发通知、重复调用、只改名的内容不能填补配额。`tools/ywc_v03_check.py --require-complete` 此前只排除隐藏事件，导致支持既有剧情的可见协议回复与续询菜单也自动加进配额。

本批新增 `data/content/v03/quota_exclusions.json`，逐条登记已确认的 11 个协议答复或操作菜单及排除原因。它们可以有真实选项、付款或伙伴决定；排除是保守的叙事配额口径，不删除玩法，也不否认它们的机制价值。已知条目仍存在且可见时，检查器会要求清单保留它们；完整门禁缺文件、JSON 重复键、清单重复 ID、空原因、未知 ID 或已隐藏的冗余 ID 均报错。一般静态检查在清单存在时也检查其合法性。

2026-10-28 当前十国目录中共有 261 个事件定义，其中 254 个可见；减去 11 个已确认的协议交互后，配额检查器最多计入 243 个。剩余可见条目**尚未逐一证明**都有独立矛盾、实际行动和后果，因此 243 是保守排除后的上限，不是已人工验收的叙事数量。60 个日志也是静态定义数，不证明每个日志有效可达。未来新增的协议菜单需经审查后加入已知集合和数据清单；没有识别的壳事件仍须人工发现。

完整配额门禁当前仍未通过；各国目标、三时期、危机、非十国与跨国主题均按原目标执行。数量检查、实际源码模型、引擎/界面和长期平衡是不同证据。本批没有启动游戏、Steam 或启动器，没有合并或发布。
