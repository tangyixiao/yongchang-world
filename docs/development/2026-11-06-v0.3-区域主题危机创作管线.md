日期：2026-11-06。适用：危机 C01–C08、区域 F01–F63、主题 T02–T12 的目录创作与配套文件。
上游合同：`docs/superpowers/plans/2026-11-01-v0.3-ZCode-完整规划与交接.md`（附件 B 是每单元的唯一内容规格）。

## 1. 交付形态

每个单元交付两部分，全部双语（zh/en 同批）：

1. **目录 JSON**（危机/主题 = 整个单元一个文件；区域 = 每政体一个"弧片段"，由主管合并进组目录）。
2. **配套手写文件**（每政体/单元独立命名，禁止共用，避免并行冲突）：
   - `yongchang_world/common/scripted_triggers/ywc_v03_<unit>_triggers.txt`（delivery/at 触发器）
   - `yongchang_world/common/scripted_effects/ywc_v03_<unit>_effects.txt`（如需支持效果）
   - `yongchang_world/common/on_actions/ywc_v03_<unit>_on_actions.txt`（如需开局挂 JE）
   - `yongchang_world/common/static_modifiers/ywc_v03_<unit>_modifiers.txt` + 两个本地化 `ywc_v03_<unit>_modifiers_l_{simp_chinese,english}.yml`（如用了自定义 modifier）

目录渲染物（events/journal/两份本地化）由主管用 `tools/build_v03_layer.py` 生成，创作者**不要**手写渲染物。

## 2. 目录 JSON 模式（校验器是唯一裁判）

参照 `data/content/v03/theme/theme_t01.json`（主题参照）与 `data/content/v03/regional/regional_mekong.json`（区域参照）。
顶层：`key`（与已登记目录一致）、`layer`（crisis/theme/regional）、`runtime_tags`（照抄现有 stub，不得增删）、`arcs`。

**弧字段**：`slug`（用注册表里已登记的 slug，一字不差）、`era`（foundation/扩展语义自定非空字符串）、`owner`、`participants`（含 owner）、`depends_on`（弧 slug 数组，禁环）、`journals`、`events`、`outcomes`（非空字符串数组，写真实结局 slug）、`legacy_links`（引用真实旧日志键，如 `ywc_je_ocean_frontiers`）。

**日志字段**：`id`（必须 `ywc_je_v03_<owner小写>_...`，全仓唯一）、`title`/`desc`（zh/en）、`script`（Clausewitz 块字符串，可含 is_shown_when_inactive/possible/immediate/on_monthly_pulse/on_complete/on_fail；**禁止**裸 `complete =`/`fail =`）、`goal`、`exit_conditions`（块字符串）。

**事件字段**：`id`（`<namespace>.NNNN`，四位数，必须落在该弧注册区间内）、`title`/`desc`/`purpose`（zh/en）、`trigger`/`immediate`（块字符串）、`reads`/`writes`（非空字符串数组，写清读了哪些真实状态、写了哪些记录）、`options`（可见事件必须非空；`hidden: true` 事件必须为空）。
**选项字段**：`key`（小写下划线、弧内唯一）、`label`/`cost_note`/`consequence_note`（zh/en）、`effect`（块字符串）、`ai_chance`（必须含 `base =` 或 `modifier =`）、可选 `trigger`。

事件 `immediate` 的固定收尾（照抄参照文件，含 `save_scope_value_as` —— 它保存在**事件自身 immediate** 内、供本事件选项读取，是引擎常规模式；**禁止**在 trigger_event 之前的发送方效果里 save scope 再跨事件读取）：

```
remove_variable = <pending>
(若无则初始化) change_variable = { name = <unit>_popup_epoch add = 1 }
save_scope_value_as = { name = <unit>_popup_epoch value = var:<unit>_popup_epoch }
ywc_v03_mark_major_delivered = yes
```

## 3. 触发器配套模式

每个事件 NNNN 一对触发器（`<unit>` 为该政体/单元前缀，如 `ywc_mhg_`、`ywc_c01_`、`ywc_t02_`）：

```
<unit>_delivery_NNNN = { c:<TAG> ?= this <unit>_live = yes var:<unit>_<line>_stage ?= NNNN var:<unit>_<line>_pending ?= NNNN ywc_v03_can_deliver_major = yes }
<unit>_at_NNNN = { c:<TAG> ?= this <unit>_live = yes var:<unit>_<line>_stage ?= NNNN scope:<unit>_popup_epoch ?= var:<unit>_popup_epoch }
<unit>_live = { is_country_alive = yes has_journal_entry = <该线 JE 键> }
```

多国单元（危机/主题）按参与者各自派生（照抄 theme_t01 的 `ywc_t01_shu_delivery_1000` → `<unit>_<tag小写>_delivery_NNNN` 写法）。JE 的 `on_monthly_pulse` 只做 `if = { limit = { <unit>_delivery_NNNN = yes } trigger_event = { id = <ns>.NNNN } }` 列表；选项推进用 `set_variable stage/pending + popup_epoch add 1`。

## 4. 费用与真实行动（质量合同）

- 费用快照：JE immediate 里 `set_variable captured_income = yearly_gross_income` → `divide = 52` → `clamp min = 100`；付款一律 `gold_reserves >= var:<fee>` + `in_default = no` + `NOT = { has_modifier = declared_bankruptcy }` 前置，付不出走"暂缓"分支（pending 不变），**禁止**免费达成或无条件扣成负数。
- 每条线至少：一个真实源动作、一次本体状态验证、一个拒绝/有限路线的有效结局；关键决定由至少两个后续节点读取。
- 法条/领土/条约不许事件直接改；只能记录承诺并读取真实立法/关系状态。已验证习语：`any_scope_state`、`country_has_building_group_levels = { type = bg_x value > 0 }`、`market_capital.market = { mg:X = { market_goods_exports > 0 } }`、`has_law = law_type:law_X`、`turmoil > 0.15`、`average_sol >= 10`、`standard_of_living >= N`、`gold_reserves >= X`、`in_default = no`、`relations`。不认识的触发器/效果/修饰符不要用。
- 自定义 modifier 必须用仓库已验证词汇（见 `yongchang_world/common/static_modifiers/ywc_v03_*.txt` 现有用词），并配双语本地化。

## 5. 创作流程（staging，不碰仓库）

1. 在 `D:\tmp\dsh-temp\v03-authoring\<unit>\` 下写目录 JSON（或区域弧片段）与配套文件。
2. 自检：`python -I D:\tmp\dsh-temp\v03-authoring\validate_staged.py "E:\Victoria3 Mod" <你的json>`（弧片段用 validate_staged_arc.py，另附组目录 key 与弧序号）。配套 .txt 与 .yml 首行必须带 UTF-8 BOM；本地化 .yml 首行为 `l_simp_chinese:` / `l_english:`（BOM 在前）。
3. 报告给主管：单元、文件清单、校验输出。主管负责入库、渲染、全量检查、提交、PR。
