# v0.3 on-action 追加兼容

## 原因与处理

安装的 Victoria 3 原版 `game/common/on_actions/_on_actions.md` 的 MODDING INFO 说明：同名 on-action 可以分文件声明，但同一个 action 不能重复拥有 `trigger` 或 `effect`；给已有回调添加效果时，应在回调的 `on_actions` 列表中追加另一个命名 action。原版 `00_code_on_actions.txt` 已为月度国家脉冲、开局、成为附庸和独立回调定义了 effect。直接向这些回调再添加 effect 会发生冲突。

本修改把蜀、朝鲜、靖海、北清、新明五个国家的月度回调、靖海/北清/新明的身份变化回调，以及无 root 的开局初始化，共 11 个 effect 搬入各自的命名子 action；原 effect 内容保留。各原版回调只追加对应子 action。每个已有项目挂载应恰好一次，这一项目约束由单独的路由测试覆盖，不视作所有 on-action 的通用语法约束。

## 静态与模型边界

`tools/ywc_check.py` 检查模组内部 effect/trigger 冲突；提供原版游戏目录时还检查与原版声明的冲突及回调引用。检查允许分文件追加和合法的重复列表项，并识别 delay、随机/首个有效子 action、fallback 与脚本中 `trigger_event` 的直接 on_action 参数。测试解释器在独立脚本链中派发项目使用的 effect/子 action 子集，覆盖原版单例与五国账本共存、开局无 root 的十国遍历及已保存作用域不在 sibling 之间泄漏。

这些检查和模型运行只证明源码、静态约束及所建模型中的行为；它们不模拟游戏调度顺序，也不证明游戏内的加载、存档、AI 或性能。没有启动游戏或 Steam，也没有进行游戏验收。
