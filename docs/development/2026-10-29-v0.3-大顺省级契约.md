## 玩家实际做什么

本线使用自己的试点变量，不改写前期税册试点。前期未参与、长期和平、没有学校或新工业都能进入；不设置固定年份强制改革，也不要求三条前期线全部完成。

| 策略 | 实际条件与支出 | 结局 |
|---|---|---|
| 中央统筹 | 本线试点官署在岗至少 0.8、无投入品短缺、现行税制基础、行政结余非负。学校/官署预算实付一周收入（最低100），救济再实付同一全额基准；六次合格月度观察。 | 两项均实付且当前条件仍成立时确立；不能用地方承诺冒认已付款。 |
| 地区共议 | 本线试点官署至少 0.25、无短缺、财政安全、和平。有真实前序地方联核权可免会务费，否则国库实付半周收入（最低50），再登记有原试点来源的本线条款并观察六个月。 | 有边界的共议妥协。条款不表示地方税或现金已经转移。 |
| 巡抚协商 | 本线试点官署至少 0.25、无短缺、和平且财政安全。可以维持旧额，不强迫学校、大学或新税法；这条路线不强制新费用。 | 有限旧额，记妥协，不能冒认为完整中央覆盖。 |

收入基准在本线开账时捕获。显示与执行共享当前资格/现金条件：中央预算只有真实已结案的前期中央财政成果、原试点仍归本国且与本线试点相同才减半；救济保持全额。前序地方权利必须有已开始的税册、真实首轮核账、有效地方权利和同一仍归本国的原试点，撤回记录不能换取免费会务。已经合法支付或免除的费用不会在旧来源记录后来变化时被追讨。

跨期测试实际走出两个不同前期决定：中央赔偿征收后，新预算支付500、重新会务支付500；地方联核后，新预算支付1000、会务免费。两处都读取真实旧源，不以注入成功旗标代替正例。旧额、撤回与未参与结果也都实际接续到中期有限路线。

## 投递、阶段与观察

流程为 1100 选本线试点 → 1101 预算 → 1102 救济责任 → 1103/1104/1105 对应执行 → 第二日志观察 → 1106 核账 → 1107 收束。

新八个 sender 追加为候选32—39，加入原 SHU 协调器的第四个 served 槽；没有第二套 reservation 或生命周期。三活跃线、六可见任务的容量限制不变，本线两日志只 claim 一次；第一日志实际 on_complete 交接第二日志，结案或退出只 release 一次。旧31个 sender、26个 immediate、六个 JE script 源 pin 保持；第四槽带来的跨线 blocker/快照生成文本按实际候选扩展。

每个选项的完整显示条件也在 effect 内重核。本线有独立的 last-event 收据，旧弹窗不能借其他线的 generic receipt 改写后续队列或重复付款。事件 trigger 不要求 sender 已移除的 pending 队列仍存在，投递来源继续由原 snapshot/epoch/ACK 证明。

观察只由第二日志的月度 helper 累计，五次不成熟、第六次成熟。创建日和同日重复回调均不计入新观察月；战争、违约、破产、失州或当前路线条件丢失会清零并等待明确延期/退出。延期不再收费，恢复后重新观察六个月。最终核账已经进入1107时，月度 helper 不会覆盖新队列；临近收束失格时仍可诚实记录受挫或退出。

## 跨期验证发现的前序修复

前期财政第二日志原来以 `register_resolved` 完成、以 `arc_abandoned` 失败，而真实1007和1009退出会同时写入二者，造成 complete/fail 同时成立。本批保留旧 resolved、outcome=4、费用和所有 sender/immediate/JE script，只令该日志的 goal 排除 abandoned，并更新对应 goal 哈希与生成输出。

新增回归在两个真实退出点先失败、修复后通过；正常地方结局仍完成并保留地方权利。相对原三条奠基 arc，只有财政第二 JE 的 goal 及其 metadata goal 哈希两个叶值变化，其他两条奠基 arc 不变。历史摘要测试断言这一处明确修正，再只逆变换它与既有所有权迁移后核对原历史摘要，没有更换原摘要来掩盖其他漂移。
