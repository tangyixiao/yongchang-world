# 朝鲜《各道留用的那一份》：省税落款与真实旧合同

2026-10-30。本卡为 v0.3 朝鲜中期内容，目录标识 `v03_kor_provincial_revenue`，包含 8 个事件（1100—1107）和 2 个日志。玩家选定当前自有朝鲜试点州，为成文分税、中央统收或项目拨款写下承办人与复核责任；连续六个月的当前事实和两笔真实支付，决定最后能够结成什么安排。

当前已分别完成 **45 个定向测试方法**，含 14 项业务、6 项真实跨期、9 项投递、4 项原生事实、3 项退出重放、2 项定价、4 项合同连续性及 3 项前置计数器测试，各模块均 exit 0。前置 3 项已属于 PR #93，并非本卡新增。国别生成、生成检查和 catalog JSON 验证均 exit 0；旧回归与独立复核的范围见本文末尾。这些是分批运行的汇总，不是一次 fresh whole suite。

## 三项财政政策有不同的现实承办者

本卡不要求旧军事、书院或港市已经完成，也不要求特定年份、工业化或外国同意。开始时选取真实自有试点，并保存该州的原生身份。后续始终读取同一个仍自有的州；另一个州的官署、军营、农场或较低动荡不能代替它。

| 完整政策 | 当前税法及岗位 | 当前承办集团与公共条件 |
|---|---|---|
| 成文分税 | 比例税或累进税；官署实际公务占用至少 80%；学校机构至少一级，试点有实际在职教育／公务岗位 | 乡村民众或知识分子中的同一个集团在政府内、政治力量至少 10%、认可度不低于 0 |
| 中央统收 | 人头税、比例税或累进税；任命官僚法；官署公务至少 80%；同州真实在职军营士兵／军官至少 80%，无短缺 | 同一个军队集团在政府内、政治力量至少 10%、认可度不低于 0 |
| 项目拨款 | 土地税或人头税；官署公务至少 50%；同州稻、麦或黍农场实际在职农民／劳工至少 50%，无短缺 | 地主或宗教集团中的同一个集团在政府内、政治力量至少 10%、认可度不低于 0 |

三种完整政策均要求官僚余额不低于 0、合法性至少 25、所选州动荡不高于 25%。集团类型、在政府内、政治力量和认可度在同一个 IG 查询中成立；就业人口必须链接到本州实际工作场所。茶园等其他农业建筑不能仅凭农业分类充当指定粮食岗位。

协议读取全国现行税法作为执行条件，不声称已经改变引擎的税收分配。选择“中央统收”不会自动通过任命官僚法，选择“成文分税”也不会替玩家通过比例税；政府组成、人口、建筑、土地与外国协议均不由本卡赠予。

## 八次责任落款

| 日志 | 事件 | 实际职责 |
|---|---|---|
| 省税留用安排 | 1100—1103 | 选政策／明确有限目标并选试点；实付立契费；按当前承办岗位与真实旧合同确定核账人；签字复核政策、目标与原始试点后交接 |
| 六个月复核 | 1104—1107 | 连续观察并实付复核费；提交已成熟账目；重审公共责任和当前合同；最终即时核验并原子结案 |

1104 的付款与提交是同一事件的两个真实动作：付款保留已经赚取的成熟证据，随后提交才能前进。1107 的完整、有限和受挫请求会执行对应的即时核验与结案，不会只写请求后等待一个不存在的调用者。

两份日志始终共用一项长期与可见任务容量。第一份日志签完之后，即使在刷新交接前失去州，第二份仍能进入等待或退出；不会偷偷换一个州继续观察。每个等待与退出按钮都受当前阶段、日志与实际回执约束。

## 两笔真实费用

开始时一次捕获 `B = max(100, yearly_gross_income / 52)`，弹窗不重算 B。

| 安排 | 立契 1101 | 复核 1104 | 基本合计 |
|---|---:|---:|---:|
| 完整成文分税 | B | B | 2B |
| 完整中央统收 | 2B | 1.5B | 3.5B |
| 完整项目拨款 | 0.5B | 0.5B | B |
| 明确有限目标，任意税法 | 0.5B | 0.5B | B |

例如年毛收入 52,000 时，B 为 1,000。无旧优惠时，三项完整政策分别实付 2,000、3,500、1,000。付款即时读取当前现金、违约、破产和财务条件，先实际扣款，再写各自独立的 paid 与正数金额。重复弹窗、缓存按钮和晚期重算不能重复扣费；已经付出的费用不退款，也不免除原有合同债务。

## 旧军事路线留下两种不同的权利

旧合同要有真实 started／settled、对应 outcome、供给与报账路线、审计与发票实付、供给承认、公开审计、六个月与九个月观察等联合证据，并继续满足当前旧路线执行条件。单个正向 outcome 不代表所有职责已经签付。

**真实地方报账合同**让完整成文分税的立契从 B 降为 0.5B，并允许在 1102 沿用地方核账权：这项核账职责只需 50% 真实公务；没有它的新核账要 80%。完整分税后续仍须恢复并保持其 80% 总体条件。定向测试在相同当前事实与现金下，实际赚取地方、中央两套历史，得到立契 500／1,000 和核账 50%／80% 两个节点的差别。

**真实中央查核合同**让完整中央统收的复核从 1.5B 降为 B，并继续读取原中央承诺与当前军营。真实旧中央、旧地方历史分别得到复核 1,000／1,500。当前军营低于要求会阻止付款；删除实际赚取的旧发票凭据后，即使保留旧中央 outcome，也不能继续领取优惠。

这两套历史均通过原始 1000—1009 事件和实际六个月、九个月观察赚取。翻译与退伍合同分别运行到 12 次真实扣款。跨期驱动按真实日历每月执行 country on_action 和 JE pulse，并将每月现金变化与实际分期增量核对。旧 `pay_monthly_supply` 增加的就绪次数没有被当作实际付款。

书院和港市合同也通过原始事件、支付、任用和连续观察赚取后再消费。书院须保留具体合作／官署路线、原账阅读、实付费用、任用与真实雇主等条款；港市须保留具体路线、立契和相关费用、既有合同核查与观察等证据。当前雇主失效或缺失真正赚取的旧账条款，会失去对应资格；未参加旧线的人使用当前新核账通路，不获得旧权利或外国同意。

## 连续六个月与明确有限目标

1103 交接后，在 phase 2、stage 1104 运行连续观察。创建日的一日锁和重复 pulse 不计作新月份；五次尚未成熟，第六次才成熟。当前税法、同一承办集团、原始试点、岗位、动荡、和平或财务任一必要条件失效，都会清除连续数、成熟与运行状态，恢复后须明确重启六个月。

有限目标是显式 target 2：原试点仍自有，真实官署公务至少 25%，官僚余额不低于 0、合法性至少 20、动荡不高于 40%，并且和平、非违约／破产、净收入不低于 0。它适用于任意现行税法和政体，不要求学校、港口、军营、特定集团或外国合作；仍须实际付款。项目拨款本身是一项完整政策，不会自动被称为有限。

完整策略失效后，玩家可以明确缩小并重算。已经支付复核费的成熟安排在选择缩小时，也须清除旧成熟与连续数，返回 1104 重新观察六个月；两笔实付保留。后段 recount 同样重新观察、不再收费，月度追踪器不覆盖 1105—1107 的阶段与队列。

完整与有限结算分别要求显式目标、当前现实条件、两笔实付、核账／签字快照一致和六次成熟。诚实受挫只在实际成熟且复核已付、当前资格失效时请求和执行；恢复后，缓存的受挫选项不能结案。主动退出独立释放本线一次容量，不完成目标，也不清理其他故事的队列或合同债务。

## PR #93 前置与旧退出修复

本卡以前置 **PR #93 的旧军事计数器初始化修复**为基础，详细见[独立开发说明](2026-10-30-v0.3-朝鲜计数器初始化.md)。实际 `ywc_kor_capture_cost_base` 仅在 `ywc_kor_ready_supply_months` 缺席时初始化为 0；已有计数与已捕获收入不重置。严格 PartnerWorld 保持原样，没有用“缺失变量加法默认零”的未核实假设放宽解释器，也没有在历史 fixture 中塞入计数器。

真实重放还发现旧军事两份日志在退出时 goal 和 fail 同时成立。此次将两个旧 JE 的 goal 加上“未 abandoned”守卫，fail 继续读取 abandoned，并更新各自的 `goal_sha256`。这是 **两处 goal 加两处 metadata 哈希，共四个 JSON 叶节点的明确例外**；其余旧三卡内容与绑定继续按基线审查。

两个实际旧退出按钮都已重放：1006 审计阶段退出、1009 服役阶段退出，各自通过严格 goal/fail 互斥检查，然后继续完成显式有限收入安排。退出后的真实已选分期仍按原 country monthly 行为支付，不靠伪造旧 outcome 或免债来打通新卡。

## 最终源码验收与审查处理

独立复核增加了四类真实源反例，而非仅核对测试数量：旧 1100 退出回调在阶段前进后仍能终止当前任务；真正旧中央合同会把有限复核价 500 覆盖为 1000，造成现金透支；完整路线忽略战争；学校／港市来源失效后保留了旧核账人资格。原始失败日志分别保留。八个退出效果现各自核来源事件的完整守卫；完整旧优惠只作用于 target1；和平与财务条件贯通观察和晚期结算。

签字、1105 责任确认和 1106 核验会重新核对采用来源。原学校／港市来源失效时，动作必须由同一试点上当前合格的新核账人实际接任，或者拒绝推进，不能继续挂着失效的旧身份。已付账保留；明确有限重签仍需六个新月份。当前 native 负控包括三个完整 mode 各自的战争、default、破产和负净收入共十二组晚期条件，恢复后缓存受挫按钮不能结案。

最后保存的源码在上述 45 项定向方法上分别 PASS；其中定价 2、连续性 4、重放 3、adapter 9、计数器 3、原生事实 4 共 25 项的源码运行前后 SHA 无漂移，业务 14 与跨期 6 另行复验。另一次冻结输入的旧回归为 **24 个模块、262 个方法，全部 exit 0、源码哈希无漂移**；现有共享 parser/inventory 8 项也重新通过。合计 33 个不同模块、315 个方法的分批最终结果，不代表全仓完整套件。

最初的外部 GLM 全源审查二十分钟超时，没有最终报告，未计为通过。其后原生代理完成实际源审查，新增上述定价／战争／来源反例；保存修复经定向复验与限定调用图复核，三项均 addressed。GLM-5.3 作者在本轮保存修改后遭服务 soft_rate 429，未完成最终报告；该外部任务仍记录为失败，没有把它的状态当成功。交付依据是当前保存源码、实际测试和独立复核。
