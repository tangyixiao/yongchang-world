## 3. 自动化资产与已知陷阱（全部沿用既有经验）

- **桌面自动化不依赖会话工具集**：Agent 有完整 shell 权限，可 `pip install pyautogui pillow` 后自写"截图 + 找色/找窗 + SendInput"脚本驱动启动器与游戏；若会话自带 computer-use 类工具更好，没有也不构成"做不了"的理由。键盘/鼠标注入只允许作用于 Victoria 3 启动器、游戏窗口和它们自己的确认框。
- **控制台 editbox 文本注入不可靠**（历史实测：重复字符、`_` 变 `-`）。缓解按优先级：
  1. 工具 Mod GUI 按钮——`tools/ywc_test_gui/`（仓库自有临时 Mod，钩住 `gui/console.gui` 加工具栏按钮）证明按钮注入可靠，需要新功能就往这个 Mod 里加按钮，用完可删；
  2. 剪贴板粘贴（`Set-Clipboard` + Ctrl+V），绕开逐键注入（待实机核对）；
  3. 单键热键（暂停/速度）不是文本框输入，可注入（待实机核对）。
- **DLC 配置只能靠官方启动器**：直接启动 exe 时 `content_load.json` 的 `disabledDLC` 被无视、所有权后端在"全拥有/不可用"间波动。所有需要 DLC 配置的启动都走启动器 UI + 对应 Playset，启动后用 `debug.log` 的 `Mounted Data:` 行核对实际挂载。
- **BOM**：为游戏写的 JSON 必须 BOM-free（PS 5.1 用 `[System.Text.UTF8Encoding]($false)`；runner 已内置，不要改回）。
- `artifacts/smoke/latest-summary.txt` 是生成文件，不能单独当证据；以 `artifacts/observe/<config>/<seed>/run.json` + logs 为准。
- 本机 cmd 环境多行 `python -c` 会被静默吞掉——一律临时脚本文件 + 断言 + 输出验证。
- 不要用键盘注入往游戏存档命名框打字（同控制台风险）：优先用默认自动存档名或剪贴板粘贴。
