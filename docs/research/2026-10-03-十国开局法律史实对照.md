# 十国与明香开局法律史实对照

日期：2026-10-03
范围：SHU、JHG、DMG、MHG、NMG、NQG、OIR、MGL、TIB、KOR、LAN

## 审查口径

- 本模组世界线中的 SHU、JHG、DMG、MHG、NMG、NQG、OIR、MGL 均属架空政权。有关它们的开局制度以项目世界观和 1836 开局剧本为依据；现实历史只用于辨认制度来源，不把游戏设定写成史实。
- TIB、KOR、LAN 以 1836 年实际政权为参照。兰芳的政治制度存在“共和”“公司”两种称谓，本文按其矿业公司联合体和实际选任方式建模，不把它等同于现代代议共和国。
- 以现有 Victoria 3 法律类型作近似映射。`law_land_based_taxation`、`law_serfdom` 等并非对应各地某一部同名法典。税率滑块 `set_tax_level = low` 不是法律，不据此断言现实税负低。
- Victoria 3 没有独立的“徭役”或“身份世袭劳动”法律组。仅在证据支持存在人身依附或世袭劳役时，才用 `law_serfdom` 作近似；它不等于完整复刻奴婢制或西欧农奴制。
- 法律证据不足时保留现有值，并将其标为模型取舍。宗教、贸易和言论三类法律尤其不能仅凭国家名或主流文化推定。
- `state_religion` 档案字段写入游戏效果 `set_state_religion`，设定国家的宗教身份；`state_religion_law` 则控制是否启用 `law_state_religion`。两者不可混称为“国教法”。没有明确国教制度依据时，应显式选用 `law_freedom_of_conscience`，不能只把国教法开关关掉。

### MGL 庄园制专项辨析（2026-10-13 补充）

- 为什么不是农奴制：本机 1.13.11 `common/laws/01_land_reform.txt` 中 `law_serfdom`（:1）带 `state_peasants_internal_migration_disallowed_bool` 与 `state_peasants_mass_migration_disallowed_bool` 迁徙锁，并把最低自给土地比例推到 0.75。草原游牧以草场轮牧为前提，属民与畜群须随季节转场，迁徙锁与牧业逻辑直接冲突；喀尔喀设定中贵族支配牧场、属民依附有限，故不取农奴制。
- 为什么是庄园制：同文件 `law_manorialism`（:74）modifier 为地主政治力量 +15%、最低自给土地 +0.5、受保护自给就业 +0.5，无迁徙锁；`parent = law_serfdom` 使地主集团沿用农奴制立场，贴合贵族支配土地的政治结构。游戏内「+50% 已整合地区的最低自治土地比例」「+50% 受保护自给就业」即后两项 modifier 的本地化显示，「+15% 地主政治力量」即第一项。
- 可见性说明：本体 `law_manorialism` 的 `is_visible` 限定奥地利与罗马尼亚文化国家，正常游玩中喀尔喀在立法界面选不到它；开局历史 `activate_law` 直接写入现行法律，不经过玩家立法流程，不受该可见性限制。这就是它只作为现行法出现在截图中的原因。
- 模型边界：庄园制的「庄园」意象来自定居农业，用它近似草原贵族对牧场与属民的支配是本模组的架空推演；沿用上文「近似」表述，不声称喀尔喀存在西欧式庄园制度。

## 实施记录

这次实际改动仅限证据充分的开局差异：

- SHU：`law_serfdom` → `law_tenant_farmers`；`law_closed_borders` → `law_migration_controls`；由 profile 增加 `law_mercantilism`；`law_right_of_assembly` → `law_censorship`。
- DMG、NQG：profile 中 `law_right_of_assembly` → `law_censorship`。
- NMG：贸易法 `law_isolationism` → `law_mercantilism`。
- OIR：宗教 `mahayana` → `gelugpa`，贸易法 `law_isolationism` → `law_mercantilism`，并将 `law_right_of_assembly` → `law_censorship`。
- MGL：在 `c:MGL` 开局块明确指定君主制、寡头制、人口税、世袭官僚、庄园制、臣民制、传统主义、农民征召和移民管制；宗教 `mahayana` → `gelugpa`，贸易法 `law_isolationism` → `law_mercantilism`，言论法 `law_right_of_assembly` → `law_censorship`。
- TIB、KOR、LAN 现有法律维持；JHG 的非宗教法律维持。逐国表已记录近似点与不确定性。
- 修正宗教法判断：SHU、JHG、DMG、MHG、NMG、NQG 从 `law_state_religion` 改为 `law_freedom_of_conscience`；仍保留儒家、天主教、大乘佛教的国家宗教身份。原版清朝、日本、大越均采用良心自由法，且大越国家定义仍写 `religion = confucian`。

## 十国开局修正案（amendments）

本节所列内容是附加在现有 active law 上的 amendment，不创建新的 law 或 law group。开局脚本按当前 active law group 添加 amendment；定义中的 `parent` 与 `allowed_laws` 限定其所依附的法律，`possible` 只允许指定国家使用。赞助集团取各项制度推演中相关的政治集团；AI 不主动撤销，仍保留原版基于合法性的 `can_repeal` 条件。效果是游戏平衡抽象，不应被读作真实历史制度带来的可量化结果。

### 盟旗共祭制：东北盟旗的国教法律（2026-10-13 补充，同日修正）

- 用户对照奥斯曼的做法，指的是**写法范式**而非内容：本体为奥斯曼量身写了一条国教组法律 `law_millet_system`（`common/laws/00_church_and_state.txt:135-241`，`tur - ottoman empire.txt:18` 开局直挂）来表达其宗教安排。照此范式，为 SOL（索伦部盟）/AMR（黑水盟）量身写 mod 专属法律 `law_ywc_banner_rites`（盟旗共祭制），位于新建文件 `yongchang_world/common/laws/ywc_laws.txt`；HUL/KHQ 信仰藏传佛教且已挂国教法，不在此列。
- 盟旗共祭制的制度语义：萨满信仰是共主主持的共同祭祀（国教），各盟旗供奉各自的神灵，互不改宗，也无从强迫。因此**不照搬米利特制的伊斯兰专属内容**：无五档异教税（吉兹亚）、无强制改宗授权（allow_conversion 五档全 no）、无征兵惩罚、无改宗效率惩罚；modifier 仅虔诚政治力量 +25%、权威 +100、国教接纳 +25、同宗教特质接纳 +10、同特质组接纳 +10、无共享特质接纳 -15。icon 复用本体 state_religion.dds。
- 结构上学米利特制：group=lawgroup_church_and_state、parent=law_state_religion、progressiveness=-50、requires_law_or{theocracy/monarchy/chiefdom}、is_visible 限 c:SOL/c:AMR、can_impose always=no、ai_will_do theocrat、ai_enact_weight_modifier journal_entries 750。本体米利特的 on_activate 自切守卫（非 TUR 且国教非逊尼则切回 state_religion）是因为它可被谈判/事件获取；共祭制仅 history 直挂且 can_impose=no，无需守卫。
- 开局挂接走 profile 管线：`data/scenario/opening_profiles.json` 的 AMR/SOL 块 `laws: ["law_ywc_banner_rites"]`，由 `tools/build_opening_profiles.py` 渲染进 `zzz_ywc_opening_profiles.txt` 的 `activate_law`。本体先例证明 activate_law 直挂不检查 is_visible/can_enact（TUR 米利特与六国庄园制均 history 直写）。
